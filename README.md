# まるロボのなるほどデジタル：動画づくり

デジタル機器のしくみを 3D アニメで解説するチャンネル「まるロボのなるほどデジタル」の、動画づくりの決まり・道具・台本をまとめた場所です。
主人公は、白い球に青緑の一つ目レンズのロボ「まるロボ」です。

## どこに何があるか

| 場所 | 中身 |
|---|---|
| `CLAUDE.md` | Claude がこのリポジトリで作業するときに、最初に守ること |
| `skill/marurobo-video-production/` | 作業の決まり（スキル）の本体。`SKILL.md` が決まり、`references/` が詳しい資料、`scripts/` が共通の道具（声・字幕・間・効果音・点検など） |
| `skill/.../references/feedback_log.md` | これまでの直し（ユーザーの指摘）の記録。同じ間違いをくり返さないためのもの |
| `episodes/ep01_earphone/` | 1本目「電車でイヤホン」（Bluetooth の音楽が途切れる・遅れるしくみ）。PC で描く一式（スキルの説明にある `assets/pc_kit`）は `episodes/ep01_earphone/stage/marurobo_tools/` |
| `episodes/ep02_qr/` | 2本目「QRコードは欠けてもなぜ読める？」の台本・図・組み立て・点検・YouTube 一式 |

## 入れていないもの

動画・声・画像・3D の描画など大きなファイルは入れていません（リポジトリが重くなるため）。
大きなファイルは Google ドライブの `marurobo_render` に置きます。どの回のどのファイルがどこにあるかは、各回の README に書きます。
例外：作り直しに手間がかかる声（仕上げ済み）と BGM の元は、FLAC にして各回の `media/` に入れています。
API キーなどの鍵も入れません（作業する環境の設定に置きます）。

## 進め方の決まり（いちばん大事な所だけ）

- 見てもらう前に、必ず自分で点検して直してから出す（機械の点検＋字のある場面をスマホの幅で見る）。報告には「見つけた所・直した所・直さなかった所と理由」を書く。
- とにかく誰が見ても分かるように。画面の字はスマホで読める大きさにし、3D の中には字を書かない（数字・式・名前は 2D の札で、字幕と同じかそれより大きく）。
- 3D の本番描画はユーザーの PC。PC に送るのは、ユーザーに頼まれてから。
- ユーザーは印刷をしない。

詳しくは `skill/marurobo-video-production/SKILL.md`。
