# PC の描画係のはじめ方（最初の 1 回だけ）

1. PowerShell を開いて、次の 1 行を貼って Enter。

```powershell
if (-not (Test-Path "C:\Program Files\Git\cmd\git.exe")) { winget install --id Git.Git -e --source winget --accept-package-agreements --accept-source-agreements }; if (-not (Test-Path C:\marurobo\repo\.git)) { & "C:\Program Files\Git\cmd\git.exe" clone -b claude/focused-cannon-l5328u https://github.com/rallenman-cmyk/marurobo-production.git C:\marurobo\repo }; powershell -ExecutionPolicy Bypass -File C:\marurobo\repo\pc_render\agent.ps1
```

2. 途中で出る画面
   - 「このアプリがデバイスに変更を加えることを許可しますか？」→ **はい**（Git を入れるため）。
   - 「Connect to GitHub」という小さな窓 → **Sign in with your browser** を押す → ブラウザで、いつもの GitHub にログイン → **Authorize**（許可）を押す。
3. 窓に「描画係をはじめます」と出たら完了。窓は置いたまま（最小化して大丈夫）。

- 次からは、PC を入れると自動で立ち上がります。
- 止めたいときは「まるロボ 描画係」の窓を閉じる。描いている途中なら「まるロボ 描き手」の窓も閉じる。
- もう一度はじめたいときは、同じ 1 行を貼る（できている所は飛ばして続きから描きます）。
- 記録は `C:\marurobo\pc_agent_log.txt`。
