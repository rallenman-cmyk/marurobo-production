## 見回りのやり方（2026-11-15 ユーザー「係が指示する感じに」「毎回 1 時間でなく、見込みに合わせて時間を変えて」）
- 見回るのは、この係のセッションだけ。各回のセッションは見回らない。終わったら係から send_message で知らせる。
- 手順：`git pull --rebase` → `python3 pc_render/notify_check.py`
  1. 「未連絡」の行があれば、依頼の session 名のセッション（list_sessions で題名から探す）に知らせる。done：「<name> の PC 描画が終わりました。ドライブ marurobo_render/<name> で本数を数えてから組み立ててください」。failed：「そろいませんでした」と tail を添える。知らせたら `notify_check.py --mark <id>` をして commit・push。
  2. 3本目（手で始めた描画）：描画係の state が「手で始めた描画が終わるのを待っています」でなくなったら 🤖03広告に知らせて `--mark manual-ep03`。
  3. `agent_error.json` がある・failed がある・待つだけのはずなのに描画係の at が 3 時間以上古いときは、原因を調べて直す。
- **次の見回りの時間**（固定の間隔にしない。send_later で 1 回ずつ予約）：描画係の `progress`（「残り N 本、およそ X」。30 分ごとに更新）から終わりの見込みを出し、**見込みの 30 分〜1 時間前まで空ける**。見込みを過ぎても終わっていなければ 1 時間ごと。待ちが空で、描画係も待つだけのときは予約しない（次の依頼が来たら、その回のセッションに「頼んだら係に send_message で一言」と README に書いてあるので、それで見回りを始める）。
- ユーザーへの報告は、終わった・止まった・同時本数が決まったときだけ。
