# まるロボ｜情報流出（盗まれる編）　構成案 v1（2026-11-23）

仮タイトル：**流出した個人情報は、どこへ行く？ 盗まれてから戻ってくるまで追いかけた**
想定尺：**約15〜16分**（前半の「どこから入られた？」は約 4 分半、後半の「名札の旅」を長く）

## 想定のサムネとタイトル（`references/expectation_5.md`）
- **タイトル**：流出した個人情報は、どこへ行く？ 盗まれてから戻ってくるまで追いかけた
- **サムネの絵**：お城（会社）の小さな裏口から、まるロボの名札（字のない札。まるロボの顔・家・電話・手紙の絵）が箱に入って運び出されていく。暗い道の先へ。後ろから、目を大きくして追いかけるまるロボ（3章の本編の場面をそのまま使う）。
- **大きな字**（帯・11〜14 字）：「盗まれた情報はどこへ行く？」（「どこへ」を黄色）
- 約束すること：盗まれた名札が、どこを通って、だれの手に渡り、どうやって自分の家に戻ってくるのかを、まるロボと一緒に最後まで追いかけて見せる。

## 0．この回のしかけ（一言で）
- まるロボに**おわびのメール**が届く所から始める。まるロボは、ある会社（お城の形で表す）の会員で、名札（名前・住所・電話・メールの札）を預けていた。「どこから盗まれた？」「名札は、いまどこ？」の 2 つの問いを冒頭で作る。
- 前半は「どこから？」：お城へ行く → 正面は固い → 裏口と漏れた合言葉 → 泥棒はすぐ盗まない → 運び出して、鍵をかける。後半は「どこへ？」：名札を追いかける → 暗い市場 → コピー → つながる → ほかのドア → 手紙になって家へ → 輪。
- 流れは「事件（おわびのメール）→ お城の正面 → 裏口 → 中を歩く泥棒 → 運び出し・鍵 → 市場 → コピー → つながる → ほかのドア → 家に戻る → 輪 → 自分でできること → まとめ → オチ」。
- **たとえの決まりを先に言う**（冒頭の終わり）：「ここでは分かりやすく、会社をお城、私たちの情報を名札、パスワードを鍵の形で表します」。画面の物は全部、本物の何かに対応させる（下の対応表）。
- 強い先（ニュースと長い対談。ゆっくり解説 41.1万回）との違い：**盗まれる所から戻ってくる所までを、1 本の旅として 3D で追いかける・まるロボ自身の名札が当事者・最後に輪になる**。
- **手口は教えない。** どの機械のどんな弱点か・使う道具・市場への行き方・泥棒の中での動き方の手順は言わない。守る側の目で、「どこが入口になるか」「盗まれたあと何が起きるか」まで。
- **会社・サービス・事件の名前、本物の見た目は出さない。**「2026 年の秋、大きな流出の発表が続きました」まで。
- **こわがらせて終わらない。** 9章で、自分でできることを 4 つ。

### たとえの対応表（画面の物 → 本物）
| 画面 | 本物 |
|---|---|
| お城 | 会社のコンピューターのまとまり（会社の中のネットワーク） |
| 正面の門 | ふだんお客さんが使う入口（ホームページなど）と、守りの機械 |
| 裏口（小さな扉） | 外から会社につなぐための出入口の機械（働く人が家や出先から中に入るための物） |

| 家のドア | ほかのサイト（買い物・メール・動画など）の入口 |
| ポストの手紙 | メール・SMS |

## 2．全体構成（約15〜16分）
流れ：**事件 → お城の正面 → 裏口 → 中を歩く泥棒 → 運び出しと鍵 → 市場 → コピー → つながる → ほかのドア → 家に戻る → 輪 → 自分でできること → まとめ → オチ**

### 冒頭　0:00〜1:30　おわびのメール
- まるロボの家（作り込んだ部屋）。朝、まるロボのスマホ（3D）にメールが届く。画面の絵：会社の印（架空。お城の形）と、短い札「情報が流出したおそれ」（2D、大きく）。
- 小窓：前に、そのお城の窓口で、まるロボが自分の名札を預けた場面（名札の 4 つの絵が光る：顔＝名前・家＝住所・電話・手紙＝メール）。
- まるロボ、自分の名札をさがして家じゅうをきょろきょろ（手元にはもともと無い）。首をかしげる。
- ナレ：「2026 年の秋、会社から、こんなおわびのメールが届いた人が、たくさんいました」（会社の名前は出さない）
- ナレ：「お客さまの情報が、流出したおそれがあります。……流出って、いったい、どこから盗まれたのでしょう？　そして、盗まれた情報は、いま、どこにあるのでしょう？」→ タイトル。
- ナレ（たとえの決まり）：「ここでは分かりやすく、会社をお城、私たち 1 人分の情報を名札、パスワードを鍵の形で表します」
- ナレ（予告 1 つ）：「これから、まるロボと一緒に、盗まれた名札を追いかけてみましょう」

### 1章　1:30〜3:15　どこから入った？（見せ場 2）
- まるロボがお城へ。正面の門：高い壁・大きな扉・見張り（無口な門番の人）。まるロボが門を押す・叩く → びくともしない。門番と並んで得意顔。
- 思い込みに先回り：「映画では、泥棒が画面に向かって速くキーボードを打ち、正面の守りを破ります。でも、本当に多いのは、そうではありません」
- カメラがお城のまわりを回る → 横の壁の低い所に、小さな扉。古い錠。まるロボはまだ正面を見ている（後ろで扉が少し開いている）。
- 裏口が何か：「これは、お城で働く人が、家や出先から中に入るための入口です。外から会社につなぐ出入口の機械を、ここでは小さな扉で表しています」
- なぜ入られる：中身が古いまま（直すのを待っている所がある）・合言葉が弱い。**直し方・弱点の中身は言わない。**
- 数字（2D のものさし型の図。字幕と同じかそれより大きい字）：「警察のまとめでは、被害にあった会社に聞いて入口が分かった 92 件のうち、61 件がこの出入口の機械、19 件が、遠くからパソコンを操作するしくみでした。どちらも、働く人が外から入るための入口です」→ 合わせて 9 割近く。
- もう 1 つ：**漏れた鍵（合言葉）**。影が、本物の鍵で裏口を開ける → 門番は通してしまう（本物の鍵だから）。ナレ：「どこかで漏れていた、働く人の ID とパスワード。本物の鍵なので、見張りも気づきにくいのです」（**8章の伏線**。どこで漏れたかは、ここでは言わない）
- 小まとめ：「泥棒は、正面ではなく、いちばん弱い 1 か所から入っていました」

### 2章　3:15〜5:30　すぐには盗まない（見せ場 3）／名札の旅 ①運び出し
- 影が、夜のお城の中を静かに歩く。カレンダーがめくれる（何日も。資料に日数の数字がないので、数字は出さない）。
- ①中を調べる：部屋を 1 つずつのぞき、えらい人の鍵束を手に入れる（「中のどこでも開けられる鍵」）。②名札の倉庫と、予備の倉庫に印を付ける。
- ③運び出す：名札の倉庫から、名札を箱につめて、裏口から外へ。**まるロボの名札も、その中に**（寄り。サムネの絵の場面）。まるロボが気づいて、追いかけ始める（3章へ続く）。
- ④最後に、全部の部屋に鍵：お城じゅうの扉に、影の鍵がガチャガチャとかかる。予備の倉庫も。働く人が扉を開けられない。注文・出荷の机が止まる。ナレ：「パソコンが開かなくなり、注文も、荷物を送ることも、できなくなります。だから、会社が止まるのです」
- ⑤2 通の脅しの手紙（字のない絵の手紙に、2D の短い札）：「元に戻してほしければ、お金を」「払わなければ、盗んだ名札をみんなに見せる」。ナレ：「鍵をかけて脅し、盗んだ物でもう一度脅す。お金を要求された 153 件のうち、136 件がこの形でした」
- 一言：「払っても、元に戻る約束も、見せないでくれる約束もありません」（IPA・警察庁で確かめた）。深入りしない。
- 鍵をかけずに盗むだけの形もある（17 件）は、入れるか台本で決める（入れるなら一言）。
- 小まとめ・橋：「では、運び出された名札は、どこへ行ったのでしょう？　まるロボが追いかけます」

### 3章　5:30〜7:15　名札の旅 ②③：暗い市場（サムネの場面）
- 夜の道。名札の箱を乗せた車（影）を、まるロボが走って追う。道がだんだん暗く、細く。ふつうの道の地図には描かれていない道へ（地図の絵から道が消える）。
- ナレ：「名札が運ばれた先は、ふつうの検索では出てこない、かくれた市場です」（**行き方・見た目は出さない**。灯りのとぼしい棚の並ぶ倉庫の形）
- 棚に箱がずらり。箱にはお城の印（架空）。まるロボ、自分の名札の箱を見つけて、値札をのぞく → 値札は小さな硬貨の絵 1 つ（**数字は出さない**。決まりは台本で）。ずっこける。
- ナレ：「盗まれた名札は、1 枚ずつではなく、たくさんの名札を並べたリストにされて、売られることがあります」（IPA の言い方「リスト化され、闇サイト等で販売される可能性」）
- 箱ごと売られる：別の影が、箱を受け取って持っていく（何人も）。

### 4章　7:15〜8:30　名札の旅 ④：取り返しても、なくならない（見せ場 4）
- まるロボが箱にとびこみ、自分の名札を抱えて逃げ出す。家まで走って、金庫にしまう。大喜び（跳ねる）。
- ナレ：「やりました。取り返しました。……でも、本当でしょうか？」
- 市場に戻ると、棚には、まるロボの名札が、まだ何枚も。さっき売れた箱の中にも。
- ナレ：「紙の名札なら、取り返せば終わりです。でも、デジタルの情報は、コピーしても元が減りません。1 枚取り返しても、同じ物が何枚でも作れるのです」（コピー機の絵ではなく、名札が光って 2 枚に分かれる動き）
- まるロボ、しょんぼり（目の光が下がる）。ナレ：「一度出た情報は、取り戻せません。では、名札は、このあと、どうなるのでしょう？」

### 5章　8:30〜10:00　名札の旅 ⑤：つながる（名寄せ）
- 買った影の机。まるロボの名札（お城 A の札：名前・住所・電話・メール）の横に、別の箱から出てきた札が並ぶ（お城 B：メール・誕生日・買った物／お城 C：電話・勤め先）。どれも、まるロボの物（顔の絵は付けない。札の形と色がちがう）。
- 同じメールの絵が、3 枚で同時に光る（線でつながない。決まり）→ 3 枚が重なって、1 冊のファイルになる。ファイルが太る。
- ナレ：「1 回の流出だけでは、分かることは少しです。でも、別の所から漏れた情報と、同じメールアドレスや電話番号を手がかりに合わせると、1 人分の、くわしい名簿になっていく。こうして名簿が作られていくと考えられています」（国の資料ではっきり書いた物がないので、言い切らない。下の 4．）
- まるロボ、自分のファイルを見て、ぞっとする（目を見開いて一歩下がる）。
- 橋：「この名簿は、何に使われるのでしょう？　使い道は、大きく 2 つあります」

### 6章　10:00〜11:30　使い道 1：ほかのドアを試す（見せ場 5）
- 町の通り。家のドアがずらり（買い物・メール・動画など、絵の看板。会社の名前・見た目は出さない）。
- 機械（小さな箱の形の機械の腕）が、名簿の鍵束を持って、ドアを次々に試す。ガチャ、ガチャ……ほとんどは開かない。
- まるロボの家の 2 つのドア：お城と同じ鍵を使っていたドア → ガチャッと開く（まるロボ、ぎょっ）。ちがう鍵のドア → 開かない。
- ナレ：「漏れた ID とパスワードの組を、機械が、ほかのサイトで次々に試します。同じパスワードを使い回していると、開いてしまうのです」
- 10本目とのつながり（一言）：「鍵は、合言葉が合えば開く。だから、同じ合言葉を、あちこちのドアに使わないことが大事です」

### 7章　11:30〜13:00　使い道 2：名前で呼ぶ手紙が、家に戻ってくる（名札の旅 ⑥）
- まるロボの家のポスト（スマホの絵も）。手紙が届く：「まるロボ様、このたびはご迷惑をおかけしました。返金のお手続きは、こちら」（2D の札。お城の印つき。本物そっくり）。
- ナレ：「流出した会社のふりをしたメールです。名前も、住所も、合っています。名簿に書いてあるからです」
- 名札が光って、手紙に変わる動き → **名札の旅が、自分の家に戻ってきた**（旅の始まりのお城と、いまの家を左右に並べた小窓）。
- まるロボ、リンクを押しかける（体ごと前へ）→ ぴたっと止まる。首をかしげ、冒頭のおわびのメールと見比べる（小窓）。
- ナレ：「漏れた名前を使って、流出した会社や、有名な会社のふりをしたメールが届くことがあります。名前で呼ばれても、それだけで本物とは限りません」
- メールのほかに、詐欺の電話・あやしい郵便物が来ることもある（一言。IPA の言い方）。「ねらう相手を選ぶ」は資料がないので言わない。

### 8章　13:00〜13:50　輪になっている（見せ場 6・後半の山）
- もし、手紙のリンクから、パスワードを入れてしまったら？（想像の場面。色を変える）→ 鍵が影の手に。
- その鍵束の中には、どこかの会社で働く人の鍵も。影がそれを持って、**別のお城の裏口へ**（1章と同じ絵の、別の色のお城）。
- ナレ：「冒頭のお城の泥棒が使っていた、漏れた鍵。あれも、こうして、どこかから流れてきた物だったのかもしれません」
- 上から引いた絵：お城 → 市場 → つながる → ドア・手紙 → 鍵 → 次のお城、が輪になって光る（線ではなく、順番に光る）。
- ナレ：「盗まれた情報は、なくならない。増えて、回って、次の入口になる。輪になっているのです」

### 9章　13:50〜15:00　自分でできること：取り戻すのではなく、使えなくする
- ナレ：「一度出た情報は、取り戻せません。だから、やることは、出た物を使えなくすることです」
- まるロボが、家じゅうのドアの鍵を、ひとつずつ替えて回る（ドアごとにちがう形の鍵）。
  1. **パスワードを使い回さない。** 漏れた所と同じパスワードは変える。
  2. **2 つ目の確かめを入れる。** 鍵が合っても、スマホに届く番号がないと開かないドア（2 つ目の小さな錠）。
  3. **おわびのメールのリンクは押さない。** 自分でいつもの入口（公式のアプリ・ブックマーク）から入って確かめる。
  4. **名前で呼ばれても、信じない。**
- 会社の側のくふう（一言、絵で）：裏口の中身を新しくする・鍵に 2 つ目の確かめ・予備の倉庫を、つながっていない所にも置く。
- ナレ：「働く人が鍵を使い回さないことは、会社の裏口を守ることにもなります」（8章の輪を、守る側から言い直す）

### まとめ　15:00〜15:40
- 問いに戻る：「流出した情報は、どこから盗まれるのか。それは、正面ではなく、古いままの裏口や、どこかで漏れた鍵から入られるからです」
- 「そして、盗まれた情報は、どこへ行くのか。それは、かくれた市場で売られ、コピーされ、ほかの情報とつながって、名前で呼びかける手紙や、ほかのドアの鍵になって、私たちのところへ戻ってくるのです」
- テーマ：「デジタルの情報は、盗まれてもなくならない。増えて、回る。だから、取り戻すのではなく、使えなくする。それが、いちばんの守りです」

### オチ　15:40〜16:10
- 鍵を全部替え終わって、まるロボがほっとして座る。スマホにメール：「まるロボ様、おめでとうございます！ 当選しました」
- ナレ：「……まるロボは、何も応募していません」
- まるロボ、ためらわずに、メールをごみ箱へ（得意顔）。

## 3．絵と部品
| 使い回す物 | 新しく作る物 |
|---|---|
| まるロボ・歩く／走る／跳ねる／ずっこける／しょんぼり／のぞき込む動き・足音・電子音（1〜15本目） | お城（会社。正面の門・高い壁・横の小さな裏口・名札の倉庫・予備の倉庫・働く人の机） |
| 作り込んだ部屋（まるロボの家。3本目・5本目の部屋） | 名札（字のない札。顔・家・電話・手紙の 4 つの絵。お城ごとに形と色をかえる） |
| スマホの画面を時刻で替える作り（5本目 `phone_seq`） | 影（泥棒。顔のない黒い形）・鍵と鍵束・扉にかかる錠 |
| 人の形（門番）（3本目〜） | 暗い市場（灯りのとぼしい倉庫の棚・箱・値札）・夜の道 |
| 4〜15本目の道具一式（組み立て・BGM・点検） | 町のドアの通り（看板は絵だけ）・機械の腕・ポストと手紙 |
| | 1 人分のファイル（札が重なって太る）・輪の引きの絵 |

- **3D の中に字を書かない**（決まり）。「流出したおそれ」「92 件のうち 61 件」「まるロボ様」などは全部 2D で重ねる。
- 色の決まり：まるロボの名札＝青緑（まるロボの目の色）・お城 B の札＝橙・お城 C の札＝緑。最後まで同じ色。影は黒、影の鍵は赤。
- 泥棒は人の顔・姿で描かない（だれかに似せない）。市場・メールの画面は、本物の見た目にまねしない。会社の印は架空（お城の形）。
- 暗い場面（夜のお城・市場・夜の道）は、暗くしすぎない（3 秒ごとの点検で「暗すぎる所」を見る）。

## 4．正確さのために気をつけること
- **入口の数字（確かめた。警察白書 令和 8 年版「ランサムウェアの情勢」）**：令和 7 年中、被害にあった会社・団体へのアンケートの有効回答 92 件のうち、VPN 機器から入られたもの 61 件（66.3％）、リモートデスクトップから 19 件（20.7％）。白書は「テレワークに利用される機器等のぜい弱性や強度の弱い認証用パスワード等の情報を利用して侵入したと考えられるものが大半」と書いている。→ 台本では「入口が分かった 92 件のうち」と分母を言う。メールからの割合は白書に数字がないので言わない。
- **二重の脅し（確かめた。同）**：お金を要求する手口と確認された 153 件のうち、136 件（88.9％）が「データを盗んだうえで、払わなければ公開する」と要求する形。
- **被害の件数（確かめた。同）**：令和 7 年中の報告 226 件（大企業 64・中小企業 143）。**鍵をかけずに盗むだけの形**：17 件。
- **すぐには盗まない・中を調べる・予備も調べる（確かめた。IPA「ランサムウェア被害から学ぶ教訓集」ver.1.2、2026 年 10 月）**：「ランサムウェアの攻撃者は時間をかけて探索し、バックアップ特定やデータ持出しを行った後、攻撃フェーズの最終段階として暗号化を開始する」。管理者の権限を取ると、中のパソコンに一斉に配れる、の説明もある。解説記事（@IT 2026-06-17）も「入る → 管理者の権限を取る → 奥へ移る（大事なデータ・予備の場所を探す）→ 持ち出す → 予備ごと暗号化」の順。→ **日数の数字は資料にないので、カレンダーは「何日も」の絵だけにし、数字は言わない。**
- **払っても戻る保証はない（確かめた。同じ教訓集）**：「身代金を支払ってもデータの回復や暴露中止は保証されない」。警察庁は「犯罪グループ等の活動資金となることが懸念される」「復号が保証されるわけではない」と説明、経済産業省は「金銭の支払いは厳に慎むべきもの」。→ 台本では「払っても、元に戻る約束も、見せないでくれる約束もありません」の一言まで。
- **かくれた市場で売られる（確かめた）**：IPA「自分の個人情報等が漏えいした際の『対処』と『日頃の対策』」（2026-10-26）に「メールアドレス、電話番号、住所、氏名等が漏えいすると、それらの情報がリスト化され、闇サイト等で販売される可能性があります」（こちらで本文を開いて確かめた）。IPA の 10 大脅威 2025 解説書［個人編］にも「ダークウェブ（一般的な検索エンジンでは検出されない闇サイト）」「売買や詐欺メールの送信などに利用される」。→ 台本では「売られることがあります」。言葉は「ふつうの検索では出てこない、かくれた市場」。
- **つながる（名寄せ）（国の説明は見つからなかった）**：別々の流出データをメールや電話番号で突き合わせる、と書いた国の資料はない。近いのは、消費者庁の名簿業者の調査（平成 28 年）の「複数の個人情報データを突合し、特定の個人に属する情報を一体化させる…名寄せ」を行う名簿業者が全体の半分ほど、と「漏えいした個人情報が複数の名簿販売事業者に転売され」。→ 台本では **「〜と考えられています」** と言い、言い切らない。「名寄せ」という言葉は使わず「合わせる」。
- **ほかのサイトで試す（確かめた）**：IPA 10 大脅威 2025［個人編］「パスワードリスト攻撃…IDとパスワードを使い回していると、それら全てのサービスでログインされるおそれ」。総務省「パスワードを複数のサービスで使い回さない」、警察庁 Letter 2026 Vol.21「すぐに安全なパスワードに変更し、使い回しはしない！」。
- **名前で呼ぶ偽のメール（確かめた）**：IPA（2026-10-26）「偽メールや偽SMSが送られてくる、詐欺電話がかかってくる、不審な郵便物が届く…偽メール等の文面に漏えいした自分の氏名が記載されているといった状況も考えられます」。警察庁 Letter Vol.21「メールやSMS内のリンクを安易にクリックしない！公式アプリや公式サイトからアクセスする！」。**「流出した会社のふり」は、はっきり書いた国の資料はなく**、広島県消費生活センターの「流出した…事業者を装った詐欺メール等や、救済を名目とした詐欺メール等が届く可能性」と、警視庁の「実在する有名企業や官公庁を装ったメール」。→ 台本では「流出した会社や、有名な会社のふりをしたメールが届くことがあります」。「流出のあとに増える」「数か月がいちばん多い」は言わない（数字の出どころがない）。
- **値段・件数（1 件いくら・何億件）**：ニュースの中の言葉なので、数字は出さない。
- **入れないこと**：会社・事件の名前、市場への行き方、機械の弱点の中身、使う道具、泥棒の中での動き方の手順、お金を払うかどうかのくわしい話。カードの番号と AI の話（17本目）。
