# まるロボ｜キーボード　構成案 v1（2026-11-15）

仮タイトル：**パソコンのキーボードは、なぜ ABC 順に並んでいない？**
想定尺：**約13〜14分**（章ごとに増減してよい）

---

## 0．この回のしかけ（一言で）
- 腕のないまるロボが、**巨大なキーボードの上を跳ねて**文字を打つ。1 回跳ねる＝1 文字。跳ねた道のりを床に線で残すと、並びの違いが「距離」で見える。
- 入口の不思議：「A」の次の「B」が、となりにない。ABC 順のほうが探しやすいのに、なぜ「Q W E R T Y」？
- **実験を先に**：ABC 順のキーボードを作って、同じ言葉を打ち比べる → 思ったほど差がない。「じゃあ、今の並びは何のため？」で昔へ行く理由ができる。
- 流れは「実験（差が小さい）→ 昔のタイプライター（最初は ABC 順だった！）→ 有名な説（からまない）は証拠がない → もう一つの説（モールス信号）→ 決着していない → なのに変わらない理由 → 手元で確かめる小ネタ → まとめ → オチ」。

## 2．全体構成（約13〜14分）
流れ：**事件（B が見つからない）→ 実験（跳ねる距離）→ 最初は ABC 順だった → 有名な説 → もう一つの説 → 変わらない理由 → 手元の小ネタ → まとめ → オチ**

### 冒頭　0:00〜1:20　「B」は、どこ？
- 机の上の巨大なキーボード（チャンネルの絵。どこの会社の物とも言えない形）。まるロボが「A」の上に乗っている。
- ナレ：「まるロボは、腕がありません。なので、キーボードは、跳ねて打ちます」→ ぴょん、カタッ。
- 次は「B」。となりを見る → 「S」。反対を見る → 何もない。キーボードの上をうろうろ、迷子。目の光がちかちか。
- ナレ：「A の次は B。……のはずが、となりにありません」
- 上から引きの絵：Q W E R T Y の並びがよく見える（2D で上の列の字を大きく）。
- ナレ：「毎日さわるキーボード。ABC 順なら探しやすいのに、どうして、こんなばらばらの並びなのでしょう？」→ タイトル。
- ナレ（引き）：「最後には、あなたの手元のキーボードで確かめられる、小さなひみつもあります」（離脱を防ぐ予告。中身は言わない）

### 1章　1:20〜3:30　実験：ABC 順なら、どれだけ楽？
- ナレ：「まるロボにとって大事なのは、跳ねる距離です。そこで、実験してみましょう」
- となりに、**ABC 順のキーボード**を置く（キーの数と形は同じ。上の列 A〜J、中の列 K〜S、下の列 T〜Z）。
- 同じ言葉を打つ：**「MARUROBO」**（自分の名前）。まるロボが 2 つのキーボードの上を順に跳ね、跳ねた道のりを床に光る線で残す（上から見た絵）。
- 結果を数字で（2D）：今の並び **28 キー分** ／ ABC 順 **31 キー分**。
- ナレ：「……あれ？　ほとんど、変わりません」
- 条件を一つだけ変える：言葉を長くする（短い日本語の文をローマ字で）。→ 今の並びが **1 割ほど短い**だけ。
- ナレ：「今の並びは、跳ねる距離を短くするための並び、というわけではなさそうです。では、いったい何のために、この順番になったのでしょう？」
- ナレ：「答えを探しに、キーボードが生まれた、150 年ほど前へ行ってみましょう」（橋）
- ※人は 10 本の指で打つので、1 本の指（まるロボ）の距離とは違う。台本で「まるロボの場合は」と一言そえる。

### 2章　3:30〜5:30　最初は、ABC 順だった
- 1860〜70年代のアメリカ。まるロボが、昔の大きなタイプライターの前へ（木と金属の、どこかの実物のまねでない形）。
- **意外な話①**：1868年、ショールズさんたちが作った最初のタイプライターは、**ピアノの鍵盤のような形で、ABC 順**だった。
  - 2 列の鍵盤。手前の列は A から N へ左から右、奥の列は O から Z へ**右から左**に並ぶ（2D で字を大きく、矢印で向き）。まるロボが鍵盤の上を A→B→C と跳ねて、うれしそう。
- ナレ：「なんと、最初は ABC 順だったのです。それなのに、なぜ変えてしまったのでしょう？」
- 並びは何年もかけて少しずつ変わる（時間の流れを、鍵盤が今の形に組み変わっていく 3D で）：
  - 1872年ごろ：ほぼ「QWE．TY」（R の場所にはピリオド）。
  - 1873年：銃やミシンを作っていた会社が作ることに。R がピリオドの場所へ。
  - 1882年ごろ：今とほぼ同じ並びに。
- ナレ：「変えた理由は、発明した人たちが書き残していません。そこで、昔から言われてきた説があります」（橋）

### 3章　5:30〜7:30　有名な説：「打つ棒が、からまないように」
- タイプライターの中へ（まるロボが入る・のぞきこむ）。キーを押すと、**細い棒が下から跳ね上がって**、紙に字を打つ。棒は円く並んでいる。
- ナレ：「よく言われるのが、『となりの棒が続けて上がると、ぶつかってからまる。だから、よく続く字を、わざと離した』という説です」
- 実際にからむ様子を見せる：まるロボが速く跳ねる → 2 本の棒が途中でぶつかって止まる → まるロボ、あわてて棒をほどく。
- ナレ：「なるほど、と思いますよね。ところが……」
- **証拠がない**：
  - ①理由を書いた記録が、残っていない。
  - ②英語でよく続く「E と R」（2 番目に多い組み合わせ）は、棒の並びでは**となり同士**だった（2 本の棒を光らせる）。
  - ③「わざと遅く打たせるため」という話もあるが、遅く打たせても、いいことがない（次の章へのふり）。
- ナレ：「からまない工夫が、少しはあったのかもしれません。でも、それだけで、この並びになったとは言えないのです」

### 4章　7:30〜9:30　もう一つの説：モールス信号（日本の研究）
- ナレ：「そこで、ここからは、日本の研究者の説を見てみましょう」
- 京都大学の安岡孝一さんたち（2011年）は、昔の記録を調べて、**最初の大事なお客さん**に目をつけた。
- それは、**電信（モールス信号）を、字に書き起こす人たち**。「トン・ツー」の音を聞きながら、すぐ打たなければいけない。
  - 3D：電信の部屋。カチカチ鳴る受信機の前で、人がタイプライターを打つ。まるロボも横で音を聞く。
- 研究の中身（いつ・誰が・何を調べて・どうだった）：当時のアメリカのモールス信号では、**「Z」と「SE」の音がよく似ていた**。聞き分けにくいので、どちらでもすぐ打てるように、**S を Z と E のそば**に置いた、と考えている。
  - 2D：「Z」の音（トントントン・トン）と「SE」の音を、点で並べて見比べる。まるロボが首をかしげる。
  - キーボードで Z・S・E を同時に光らせる（線で結ばない）。
- ナレ：「お客さんの使い方に合わせて、少しずつ変えていったら、今の並びになった、という考えです」
- **ただし、決着していない**：この説にも「証拠が足りない」という反論がある。棒がからまない工夫こそ大事だった、という人もいる。
- ナレ：「キーボードの並びが、なぜこうなったのか。実は、今でも、はっきりとは分かっていないのです」

### 5章　9:30〜11:15　それでも、変わらなかった
- ナレ：「でも、ここで、もう一つ不思議なことがあります。理由がはっきりしないなら、もっと良い並びに変えればいいのでは？」
- 1893年、アメリカの大きなタイプライターの会社がまとまり、この並びが**決まりのような形**になった。習う人も、教える学校も、この並び。
- その後、電報の機械・コンピューターへと、並びがそのまま引きつがれる（3D：タイプライター → 古い端末 → 今のキーボードへ形が変わっていく。字は 2D の年だけ）。
- **もっと速いと言われた並び**：1936年、ドボラックさんが考えた並び（2D で並びを出す）。
  - 「ずっと速い」とした実験には、考えた本人が関わっていた。
  - あとの別の研究では、**はっきり速いとは言えなかった**（今も議論はある）。
- そして何より：ナレ「もし本当に速くても、何百万人がもう今の並びを覚えています。覚え直す手間のほうが、ずっと大きいのです」
  - たとえ：まるロボの前に、今の並びで打つ人がたくさん（3D の人の形。全員が同じ並び）。新しい並びのキーボードを 1 台置いても、誰も座らない。
- ナレ：「こうして、一度決まった並びは、150 年近く、ほとんど変わらなかったのです」

### 6章　11:15〜12:30　手元で確かめよう：F と J・かなの字
- ナレ：「では最後に、冒頭でお話しした、小さなひみつです。あなたの手元のキーボードの、F と J をさわってみてください」
- アップ：F と J に、小さな**でっぱり**（3D で横から光を当てて見せる）。まるロボが F に乗って、足もとで確かめる。
- ナレ：「画面を見たまま、指の置き場所を、さわって見つけるための目印です」（両手の人差し指を F と J に置く絵。数字のキーがあれば「5」にも）
- **（入れるか聞く）日本のキーボード**：キーに、ひらがなも書いてある。でも、調べると**9割ほどの人はローマ字で**打っている（調査は 2015年）。ナレ「かなの字は、実は、あまり使われていないようです」
- **（入れるか聞く）斜めのずれ**：キーは段ごとに少しずつ横にずれている。タイプライターの棒の都合の名残、と言われている（言い切らない）。

### 7章　12:30〜13:20　まとめ
- 問いに戻る：「キーボードは、なぜ ABC 順に並んでいないのか」
- →「最初は ABC 順だったものを、使う人や作る会社の都合に合わせて、少しずつ変えていったからです。その理由は、今でもはっきりしていません。そして、一度みんなが覚えると、もっと良い並びが出ても変わらなかったからです」
- 「毎日さわっているキーボードには、150 年分の、使った人たちの歴史がつまっていたのです」

### オチ　13:20〜14:00　まるロボ専用の並び
- まるロボが、跳ねる距離がいちばん短くなる並びを考える（キーがくるくる入れかわる → 新しい並び。計算で出した並び）。
- 同じ文を打つと、跳ねる距離は**今の並びの半分**（2D の数字）。まるロボ、得意げ。
- その並びのキーボードを机に置く → 人の手が来て……となりの、いつものキーボードを使う。
- ナレ：「……まるロボの並びも、誰にも覚えてもらえなかったようです」

## 3．絵と部品
| 使い回す物 | 新しく作る物 |
|---|---|
| まるロボ・跳ぶ動き・足音（1〜6本目） | 巨大なキーボード（今の並び・ABC 順・まるロボ専用。キーの形は同じ、字は 2D） |
| 人の形（3本目〜） | 1868年のピアノのようなタイプライター・1870年代のタイプライター（棒が円く並ぶ中まで） |
| 4・5本目の道具一式（組み立て・BGM・点検） | 跳ねた道のりの光る線（上から見た絵）・電信の部屋と受信機 |
| | F と J のでっぱりのアップ |

- **3D の中に字を書かない**（決まり）。キーの字は全部 2D で重ねる。キーが多いので、見せるのは**話に出る字だけ**大きく（全部のキーに字を出すとスマホで読めない）。上から見た絵では、上の列「QWERTY」と、跳ねる字だけ。
- 跳ねた道のりの線は、今の並び＝青、ABC 順＝橙、まるロボ専用＝緑で最後までそろえる。
- タイプライターも今のキーボードも、実在の会社の形・ロゴのまねをしない。会社名は出さない（「銃やミシンを作っていた会社」）。

## 4．正確さのために気をつけること（2026-11-15 に元の資料で確かめた）
- **由来は言い切らない。** 「〜という説があります」「〜と考えています」。安岡さんたちの論文も「まだ分かっていない」と書いている。
- **「わざと遅く打たせるため」は、はっきり否定されている**（言ってよい）。一方「棒がからまない工夫が少しはあった」は否定しきれない → 「それだけで、この並びになったとは言えない」と言う。
- **最初の並び（1868年）**：ピアノのような 2 列、A〜N を左から右、O〜Z を右から左（論文の本文）。「A〜M／N〜Z」ではない。
- **Z と SE**：論文の例は「Z が SE と取り違えやすいので、S を Z と E のそばに」。論文の中でも「私たちの考えでは」と書いている。「SC」の例はない。
- **1873年の契約**：会社と契約したのはショールズさんでなく仲間のデンスモアさん。台本では「1873年、銃やミシンを作っていた会社が作ることになった」と、人の名前を出さずに言う。
- **ドボラック配列**：1936年の特許（考えたのは 1932年）。「75% 速い」という数字は言わない（その実験は本人が関わっていて、議論がある）。あとの研究の年（1956年）は確かめられていないので言わない。
- **F と J のでっぱり**：目的だけ言う。「〇〇さんが発明した」は言わない（よく出回る 2002年の特許の話は、別の物で誤り）。
- **ローマ字 9割**：2015年の調査（約 1,500 人・ネットで、パソコンに詳しい人が多め）で 93%、2007年の別の調査で 86%。「調べると、9割ほど」と言い、年も出す。
- **斜めのずれ**：タイプライターの棒の都合の名残、は広く言われている説明だが、博物館・論文の資料は見つかっていない → 入れるなら「〜と言われています」。
- **跳ねる距離**：キーの中心どうしのまっすぐな距離を、キー 1 個分を 1 として足した。段のずれは今のキーボードと同じ（1/4・3/4 キー）にした。
  - 「MARUROBO」：今の並び 28.1 ／ ABC 順 30.8。
  - 短い日本語の文（ローマ字、約 60 語）：今の並び 837 ／ ABC 順 947（約 1 割短い）／ まるロボ専用 412（約半分）。
  - 文は台本で決めて計算し直す。数字は四捨五入して見せる。

## 5．決めてもらうこと（質問の画面で聞く）
1. 1章の実験の結果「ほとんど変わらない」を、話の入口に使うか（使う＝実験を前に。使わない＝企画案どおり歴史のあとに実験）。
2. 6章の小ネタに「日本のかな・ローマ字」を入れるか。
3. 6章の小ネタに「キーの斜めのずれ」を入れるか（言い切れない説）。
4. オチは「まるロボ専用の並びが誰にも使われない」でよいか。
