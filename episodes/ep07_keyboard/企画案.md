# 企画案：パソコンのキーボードは、なぜ ABC 順に並んでいない？（2026-11-15）

## 一言で
毎日さわるキーボードの「Q W E R T Y……って、なんでこの順番？」を、まるロボが巨大なキーボードの上を跳ね回って確かめる回。ユーザーの方針「日常のなぜ」の 1 本目。

## 入口の問い
- キーボードの左上は「Q W E R T Y」。ABC 順の方が探しやすいのに、なぜこんなばらばらな並び？
- そういえば、F と J だけ、でっぱりがあるのはなぜ？

## 答え（言いたいこと）
1. **有名な説「打つ棒がからまないように、わざとばらばらにした」は、はっきりした証拠がない。** 並びを決めた発明家（1870年代のタイプライター）は、理由を書き残していない。
2. **日本の研究者の新しい説**：京都大学の安岡孝一さんたちの研究（2011年）では、最初の大口のお客さんだった「電信（モールス信号）を文字に書き起こす人たち」の使い方に合わせて、少しずつ並びを変えていった、と考えている。（ただし、この説にも反論がある。「まだ決着していない謎」として話す）
3. **一度決まると、変わらない**：「もっと速い」と言われた並び（1930年代のドボラック配列）もあったが、ちゃんと比べると、はっきり速いとは言えないという研究もある。何より、みんながもう今の並びを覚えてしまった。だから 150 年近く変わらない。
4. **身近な小ネタ**：F と J のでっぱりは、画面を見たまま、人差し指の置き場所を手さぐりで見つけるための目印。キーが少しずつ斜めにずれて並んでいるのも、タイプライターの名残と言われる（← 確かめる）。
5. **日本ならでは**：日本では、かなが書いてあるのに、多くの人はローマ字で打っている（← 割合は資料で確かめる）。

## 面白いポイント（山場の候補）
| ポイント | なぜ面白いか |
|---|---|
| まるロボ（腕がない）が、巨大なキーボードの上を跳ねて文字を打つ | 3D の見せ場。打つたびに足音とキーの音 |
| ABC 順のキーボードと今の並びで、同じ言葉を打つ「跳ねる距離」を比べる | 実験の形で、並びの違いが体で分かる（距離は計算して数字で出す） |
| 「からまないため」は、実は証拠がない | 誰もが聞いたことのある話がひっくり返る |
| 答えの手がかりは「モールス信号」、しかも日本の研究者 | 意外な所から答えが出てくる |
| 速い並びが作られても、みんなが覚えた方が勝つ | 「なるほど、だから変わらないのか」と納得できる |
| F と J のでっぱり | 見ている人が今すぐ手元で確かめられる |

## 構成のたたき台（約12〜15分）
1. **冒頭**：まるロボがキーボードの上で、「A」の次の「B」を探して迷子になる。「なんで ABC 順じゃないの？」
2. **問い**：Q W E R T Y の並びは、誰が、なぜ決めた？
3. **タイプライターの時代へ**：1870年代。打つ棒が並ぶ機械の中にまるロボが入る。
4. **有名な説**：棒がからまないように……？ → 実は証拠がない。
5. **もう一つの説**：電信の人たちと、日本の研究。まだ決着していない謎。
6. **実験**：ABC 順と今の並びで、同じ言葉を打つ距離を比べる。
7. **もっと速い並びがあっても変わらない理由**：みんなが覚えたから。
8. **小ネタ**：F と J のでっぱり（見ている人も手元で確かめる）。
9. **まとめ**：問い →「〜からです」。
10. **オチの案**：まるロボが「跳ねる距離が一番短い、まるロボ専用の並び」を作るが、誰にも使ってもらえない。

## 向いている所
- 「日常のなぜ」にぴったり。見ている人の手元にある物で、今すぐ確かめられる。
- 「有名な説がひっくり返る」「日本の研究者」という、ほかの解説と違う切り口がある。
- 巨大なキーボードの上を跳ねるまるロボは、絵として強い。

## 気をつける所
- 並びの由来は、まだ決着していない。「〜という説があります」「〜と考えている研究者もいます」と、言い切らない。
- 安岡さんたちの研究と、その反論は、元の論文・記事で確かめてから台本に入れる。
- ドボラック配列の速さの比べは、どちらの立場の資料かに気をつける。
- 本物のキーボードの会社の名前・形のまねをしない（チャンネルの絵で描く）。
