## 0．この回のしかけ（一言で）
- まるロボが**自分のかばんに乗って、のれんの奥へ付いて行く**。かばんの目線で「なぜ迷わない？」を追う。
- 前半は「だれが道を決めている？」：ベルトの部屋（人がいない）→ タグの番号 → 読み取りの門 → 読めないと人の部屋へ。
- 後半は「どうやって自分の飛行機へ？」：コンピューターの「いまここ」→ 小さな台車で輪を回って出口でぽん → 電波のタグ → 人が積む → 着いた空港。
- 流れは「預ける → のれんの奥 → 問い（だれが道を？）→ タグの番号 → 読み取りの門（ブー）→ 人の部屋 → 検査（ごく浅く）→ いまここ → 分かれ道 → 電波のタグ → 飛行機の前 → まとめ → オチ」。
- 強い先（カメラを付けて追う動画 32.1万回ほか）との違い：**カメラは「見えた物」だけ。こちらは、番号を読む → 名簿と照らす → 場所を追う → 出口を決める、の目に見えない所まで見せる**。まるロボが当事者（タグを隠すドジ）。
- **空想の旅だと、はっきり分かる見せ方にする。** 冒頭で語りが「本当は、かばんに乗ることはできません。ここからは、小さなまるロボと一緒の、空想の旅です」。
- **検査はごく浅く**：「あぶない物が入っていないか、機械が調べます。気になるかばんは、人が確かめます」まで。機械の中身・見え方・やり方は見せない。
- **空港・航空会社・メーカーの名前、本物の建物・機械・タグの見た目をまねない。** タグも架空の柄（空港の 3 文字は架空のもの）。
- 2本目（QR）・12本目（地図アプリ）とかぶらせない：しま模様の読み方のしくみ（線の太さ）は言わない。「番号が入っている」まで。「番号で行き先を決める」に集中。

## 2．全体構成（約14分）
流れ：**預ける → のれんの奥 → タグの番号 → 読み取りの門 → 人の部屋 → 検査 → いまここ → 分かれ道 → 電波のタグ → 飛行機の前 → まとめ → オチ**

### 冒頭　0:00〜1:40　のれんの奥へ（サムネの場面①）
- 空港の出発ロビー（どこの空港とも言えない形。作り込んだ舞台）。まるロボが、自分と同じ丸い柄のかばんを転がしてくる。旅行。
- カウンター：係の人がかばんにタグを巻く（字は 2D で後から。3D には書かない）。かばんはベルトに乗り、ゆっくり奥へ。黒いのれんが揺れる。
- ナレ：「まるロボ、はじめての飛行機の旅です。かばんを預けると、ベルトに乗って、あの黒いのれんの奥へ消えていきます」
- まるロボ、心配そうにのぞく → かばんがのれんに入る直前、ぴょんと跳び乗る → 一緒に吸いこまれる（**サムネの絵**）。
- ナレ：「本当は、かばんに乗ることはできません。ここからは、小さなまるロボと一緒の、空想の旅です」
- 問いをふくらませる：引きの絵。カウンターがずらり。次々に消えていくかばん。行き先の掲示（架空の行き先が何十も）。
- ナレ：「同じ時間に、何千個ものかばんが、何十もの行き先へ。それなのに、着いた空港では、ちゃんと自分のかばんが出てきます」
- ナレ：「あの奥で、いったい何が起きているのでしょう？」→ タイトル。
- ナレ（予告 1 つ）：「まるロボと一緒に、奥まで付いて行ってみましょう」

### 1章　1:40〜3:00　ベルトの迷路（サムネの場面②）
- 暗いトンネル → 急に広い部屋。ベルトが何本も、上ったり下ったり、合流したり。まるロボ、目を回す（ジェットコースターのように）。
- 気づき：まわりを見る → 人がいない。かばんだけが、次々に分かれ道を曲がっていく。
- ナレ：「ふしぎです。ここには、道を教える人がいません。それなのに、かばんは迷わず、どこかへ曲がっていきます」
- 問い：「いったい、だれが、かばんの道を決めているのでしょう？」
- まるロボ、自分のかばんの取っ手に巻かれたタグに気づく。

### 2章　3:00〜4:40　見せ場 2：タグのしま模様の中身
- タグの寄り：名前・空港の 3 文字・便の番号・しま模様（2D で大きく字を重ねる。架空の名前「マルロボ」など）。
- まるロボ、しま模様を読もうと目を近づける → 読めない →「？」。
- ナレ：「タグには、名前や行き先も書いてあります。でも、機械が読むのは、このしま模様だけ。中に入っているのは……10 けたの番号だけです」（答えは「……」で分ける）
- 思い込みに先回り：「えっ、行き先は入っていないの？」→ 入っていない。
- たとえ：**宅配便の追跡番号**（見ている人の体験）。番号を打てば、荷物が今どこか分かる。番号そのものには住所は入っていない。荷物の会社のコンピューターが、番号と住所をつないで覚えている。
- 本物では：チェックインのとき、航空会社のコンピューターが、仕分けの機械のコンピューターへ「この番号のかばんは、この便」と知らせている（光る名簿の棚に、まるロボのかばんの行が 1 行増える絵）。
- 小まとめ：「タグの番号が名簿の行を指し、名簿が行き先を教える。こういう順番です」
- 橋：「では、その番号を、だれが読むのでしょう？」

### 3章　4:40〜5:50　読み取りの門（サムネの場面③）
- 前の方に、光の線がいっぱいの門。前のかばんたちが通る → ピッ、ピッ（読むたびに名簿の行が光る）。
- ナレ：「この門は、上からも横からも下からも、光を当てて、タグがどこを向いていても読もうとします」（タグが裏・横・下を向いたかばんでも、ピッ）
- まるロボの番。得意げにポーズ。……でも「ブー」。赤いランプ。
- 引いて見ると、まるロボがタグの上に座りこんでいた（ドジ）。
- ナレ：「まるロボ、タグの上に座っていました。光が、しま模様まで届きません」
- かばんは、ほかと別の道へそれていく。「どこへ行くの？」

### 4章　5:50〜7:00　見せ場 3：読めなかったかばんの行き先（人の部屋・サムネの場面④）
- 明るい小部屋。係の人（無口で手際がいい人）が待っている。
- 係の人、まるロボの下からタグを引っぱり出し、手で持つ読み取り機でピッ。かばんはベルトに戻される。まるロボ、もじもじ。
- ナレ：「読めなかったかばんは、人が確かめる場所へ。係の人が手で読み直して、もう一度、流れにもどします」
- 読めない理由（責めない言い方）：タグが折れる・ぬれる・ほかのかばんの下にかくれる。だから、人の手でも確かめられるように作ってある。
- 小まとめ：「機械が読めなければ、人が読む。2 重に見守っています」

### 5章　7:00〜8:30　検査と、だれもいない部屋の「いまここ」（見せ場 4）
- 大きな箱のトンネルをくぐる（中は見せない。光がすっと通るだけ）。
  - ナレ：「途中で、あぶない物が入っていないかを、機械が調べます。気になるかばんは、人が確かめます」（これだけ。空港によって、順番や場所はちがう）
- 場面がかわる：だれもいない部屋の大きな画面（3D）。ベルトの地図の上を、光る点が何千も動いている。1 つが、まるロボのかばん（色をそろえる）。
- 問い：「門で番号を読んだのは、1 回だけ。それなのに、かばんが今どこにいるか、どうして分かるのでしょう？」
- 答え：読んだ場所と時刻と、ベルトの速さが分かれば、いまどこまで進んだか計算できる。途中にも、通ったかを見る目（光の目）がある。
- ナレ：「コンピューターは、全部のかばんの『いまここ』を追いながら、分かれ道の手前で、ベルトに『右へ』『まっすぐ』と指示を出しています」
- 小まとめ：「番号を読む → 名簿で行き先が分かる → いまここを追う → 分かれ道に指示。かばんの道を決めていたのは、この流れです」

### 6章　8:30〜10:20　分かれ道でぽん（サムネの場面⑤・この回の山場）
- まるロボのかばん、小さな台車に乗りかえる（台車がずらっと並んで、輪になって回っている。台車の上に、横向きの小さなベルト）。
- 速い：景色が流れる。ナレ：「空港の仕分けの機械には、時速 30km をこえる速さで運ぶ物もあります」（空港によってちがう。数字の札は台車に重ねず、画面の上に）
- 輪の外側に、出口（すべり台）がずらり。行き先ごとに色の札（2D）。
- となりの台車のかばん：その出口の前で、台車のベルトが横に回って、ぽん。すべり台へ。まるロボ、ヒヤリ（自分も落ちる？）→ 目をつぶる。
- まるロボの出口が近づく（地図の点も近づく）。ナレ：「まるロボのかばんの番号は、この便の名簿の行。だから、出口は……ここ」→ ぽん。すべり台をすべって、行き先ごとの場所へ。
- ナレ：「物を運んでいるのはベルト。でも、どの出口で降りるかを決めているのは、タグの番号です」

### 7章　10:20〜11:30　見せ場 5（後半の山）：電波で読むタグ
- ナレ：「ここで、さっきのまるロボを思い出してください」→ 3章の「ブー」を左上の小窓で。
- 新しいタグ：小さな部品と、電波の輪（字のない絵）。まるロボがタグの上に座っても → ピッ。かばんの下でも、ぬれても、読める。
- ナレ：「電波で読むタグなら、光が届かなくても読めます。座っていても、大丈夫です」（まるロボ、ちょっと得意げ）
- 本物では：電波で読むタグを使い始めた空港や航空会社がある。世界の航空会社の集まりも、使うように勧めている（どこの名前も出さない）。
- 小まとめ：「しま模様は光で読む。電波のタグは、見えなくても読む。どちらも、中身は同じ番号です」

### 8章　11:30〜12:50　飛行機の前で（サムネの場面⑥）
- すべり台の下：行き先ごとの場所。係の人たちが、かばんを便ごとのコンテナへ積んでいく（タグを見て、確かめながら）。
- ナレ：「最後は、人の手です。係の人が、かばんを便ごとのコンテナに積みます。1 つのコンテナに、40 個以上入ることもあります」
- まるロボ、コンテナの中で、ほかのかばんとならんでちょこんと座る。とびらが閉まる。引っぱる車で飛行機の下へ → 持ち上げる台で、おなかの荷物室へ。
- 乗りつぎの話（短く）：着いた空港で、次の飛行機に乗りつぐかばんは、そこでもう一度番号を読まれて、次の便へ。時間が短いので、届くのが遅れるかばんがいちばん多いのは、この乗りつぎのとき（2024年は、届くのが遅れるなどしたかばんの 4 割ほど）。
- ナレ（責めない）：「見えない所で、機械と人が、時間と競争しながらリレーしているのです」

### 9章　12:50〜13:40　まとめ
- 問いに戻る：「何千個ものかばんが、なぜ自分の飛行機に届くのか。それは、タグの番号を機械が読み、名簿で行き先を知り、コンピューターが『いまここ』を追いながら、分かれ道で出口を選んでいるからです」
- 「読めないときは人が読み、最後は人が積む。機械と人のリレーで、かばんは運ばれていたのです」
- 引きの絵：ベルトの迷路全体が透けて、何千もの点が、それぞれの出口へ流れていく。
- テーマ：「かばんを運んでいるのはベルト。でも、行き先を決めているのは、タグの小さな番号 1 つ。その番号が、かばんを世界のどこへでも連れて行くのです」

### オチ　13:40〜14:10
- 着いた空港。回るベルトから、かばんが次々に出てくる。その 1 つに、まるロボが乗ったまま出てくる。まわりの人が二度見。

## 3．絵と部品
| 使い回す物 | 新しく作る物 |
|---|---|
| まるロボ・跳ぶ／跳び乗る／目を回す／のぞき込む／もじもじ動き・足音・電子音（1本目〜、`maru_motions.md`） | 出発ロビーとカウンター・黒いのれん（どこの空港とも言えない形） |
| 人の形・手（3本目〜）、係の人 | ベルトの迷路（上り下り・合流・トンネル）・読み取りの門（光の線） |
| 9本目の「いまここ」の小さな地図・小窓（`fig_anim.pip`） | 光る名簿の棚・人の部屋（手で持つ読み取り機）・検査の箱（中は見せない） |
| 4〜9本目の道具一式（組み立て・BGM・点検・突き抜けの点検 `pen_check.py`） | 輪になって回る小さな台車（横向きのベルト）・出口のすべり台・行き先ごとの場所・コンテナと車・飛行機の下側 |
| | かばん（まるロボと同じ丸い柄）とタグ・電波のタグ・着いた空港の回るベルト |

- **3D の中に字を書かない**（決まり）。タグの名前・3 文字・番号・行き先の札・「時速 30km」は全部 2D で重ねる。
- 色の決まり：まるロボのかばん（と地図の点・名簿の行）＝1 つの色（例：青緑）で最後までそろえる。ほかのかばんの点は白。
- かばんが台車・すべり台・ほかのかばんを突き抜けない。まるロボがかばんの上で浮かない（毎コマ、かばんの上面に合わせる）。つなげた動画と `pen_check.py` で必ず確かめる。
- 小さな物（タグ）を見せる場面は、カメラ→タグの間をさえぎる物を数えて 0 にしてから描く（9本目の決まり）。
- 本物の機械・空港・会社の形をまねない。名前は出さない。

## 4．正確さのために気をつけること（2026-11-23 に元の資料で確かめた）
- **タグの番号は 10 けた**：はじめの 1 けた・タグを出す会社の 3 けた・6 けたの続き番号（IATA の説明書）。番号の決まりは IATA の決議 751。バーコードには 10 けたが全部入る。
- **タグには名前や行き先も印刷されている**（Wikipedia「Bag tag」）。→ 企画案の「名前は書いていない」はまちがいなので、**「機械が読むしま模様には、番号だけ」**と言う。
- **番号から行き先が分かるしくみ**：番号は、航空会社のチェックインのコンピューターが空港の仕分けのコンピューターへ送る知らせ（BSM。便や乗る人の情報）を指す目じるし。番号と知らせの両方がそろって、自動で仕分けできる（Wikipedia「Bag tag」）。日本の航空会社の説明も「タグの情報から自動的に行き先に振り分けられます」（JAL の記事 2019・2021）。
- **読み取りの門**：レーザーやカメラを輪のように並べ、いろいろな向きから読む。読める割合は、悪いと 85% ほど、条件が良いと 99.5% ほど（Wikipedia「Bag tag」）→ **数字は言わず「ほとんど読めるが、読めないこともある」**。
- **読めなかったら人が読む**：「係員が手作業で再度読み取ることになり」（Aviation Wire 2024-02-16、成田空港会社の発表の記事）・「bags are shunted off for manual reading」（Wikipedia「Bag tag」）。
- **仕分けの機械**：「海外ではティルトトレイ方式が多いが我が国では手荷物制限が少なく、手荷物への衝撃が少ないクロスベルト方式が主流」（国の資料 001216812、機械メーカーの報告）。ソーターが一般的になったのは 1990 年代ごろから、IATA のバーコードタグの標準化のおかげ（同）。メーカーの説明でも「空港採用実績世界 No.1 のクロスベルトソータ」（国の資料 1-14）。横にすべる分かれ道は 1 時間に 2,400〜3,600 個（国の資料 1-17）。
- **速さ**：速い物は、トレイ型で分速 600m（国の資料 1-13、時速 36km）、海外の運ぶ機械で時速 20 マイル（約 32km）をこえる物（メーカーの説明）→ **「時速 30km をこえる物もある。空港によってちがう」**。クロスベルトの台車の輪の速さの数字は見つからなかった → **台車の輪の絵に「時速 30km」を重ねない**。6章では「空港の仕分けの機械には、時速 30km をこえる物もあります」と、機械全体の話として言う。
- **いまここを追う**：トレイに組みこんだ位置の情報を読んで追う（国の資料 1-13）、ベルトの分かれ道で追いかけを確かにする（国の資料 1-14）。数えて追うのは仕分けのしくみの役目（Wikipedia「Baggage handling system」）。
- **検査**：仕分けの道に、爆発物を調べる機械が組みこまれている（国の資料 1-17「インラインスクリーニング」）→ 台本では「あぶない物がないか機械が調べ、気になるかばんは人が確かめる」まで。
- **最後は人**：仕分け場で、係の人が各便のコンテナに積む。1 つのコンテナに 40 個以上。小さな飛行機は 1 個ずつ手で積む（JAL の記事 2019・2021）。積むのを手伝うロボットを入れた所もある（国の資料 001994353）が、この回では入れない。
- **早く預けたかばん**：羽田の第 3 ターミナルでは、早く預けたかばんをベルトで一時置き場へ出し入れしている（国の資料）→ この構成では入れない（新しい物を増やさないため。入れるならユーザーに聞く）。
- **電波のタグ**：バーコードは、見えていて傷のないときしか読めない。電波のタグは、使い始めた空港・航空会社がある（Wikipedia「Bag tag」）。IATA は追いかけ（決議 753、2018年から）とともに電波のタグを勧めている。**日本の大手での本格的な使い始めは見つからなかった** → 「使い始めた所がある」とだけ言い、日本で広がっているとは言わない（企画案の「広がっている」を弱める）。
- **届くのが遅れるかばん**：2024年、世界で乗る人 1,000 人に 6.3 個。いちばん多い原因は乗りつぎ（41%）（SITA の発表 2025-06-12）。2025年は 4.9 個・乗りつぎ 39% という報道もあるが、元の報告書は読めなかったので、使うなら 2024年の数字。
- **入れないこと**：検査の中身・見え方、すり抜けにつながる話、本物の空港・航空会社・メーカーの名前、「なくならない」の言い切り、だれかのせいにする言い方。

## 5．決めてもらうこと（質問の画面で聞く）
- 冒頭の「かばんに乗る」の見せ方（空想の旅と言う／言わずに絵だけで）
- 3章の読めない場面（まるロボがタグに座る／タグが折れる）
- 検査の場面の長さ（約 30 秒／一言だけ）
- 乗りつぎの話の入れ方（8章で短く／入れない）
