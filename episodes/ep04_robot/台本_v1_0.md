# まるロボ｜私はロボットではありません　台本 v1.0（確定）

題：ロボットが「私はロボットではありません」を押したら？（仮）  
想定尺：ナレーション約3,000字・120本ほど（声で約10分）。間と見せ場を入れて約13〜14分。  
舞台：A＝まるロボの部屋（現実。机の上にノートパソコンとマウス）／B＝パソコンの画面の中（広い床と、奥にチェック欄の門）／C＝昔の新聞の倉庫（2D と 3D の間の、紙の山の場面）  
人：画面には出さない。ナレーター（私）が外からマウスを動かす。マウスはひとりでに動いて見える。  
足あと（最後まで同じ表し方）：私の矢印＝オレンジの足あと（くねくね・寄り道・一度止まる）／まるロボの矢印＝青緑の足あと（まっすぐ・同じ速さ）  
門番：チェック欄の門の横に立つ係。人らしさの点を、目盛りの光で示す（数字は 2D）。3本目の見張り番の形を使い回す。  
しるし：＝台本を確定する前に、元の資料でもう一度確かめる  
まるロボ：**喋らない**。字の吹き出しも使わない。気持ちは身ぶり・目の光・電子音（ピポ）と、字のない絵の吹き出し（？・！・テントの絵・信号機の絵）で出す。腕はないので、マウスは体で押し、ボタンは跳び乗って押す。  
字：3D の中には書かない。「私はロボットではありません」・ゆがんだ文字・数字・年は全部 2D で、字幕と同じかそれより大きく。本物の画面のまねはしない（チャンネルの色と形で描く）。
