## 作る前に確かめること
- 大きなスマホの画面の絵の向き（12本目の決まり：2D の同じ絵と並べて、上下・左右）。
- まるロボがスマホに跳び乗る高さ（0.03 m）・画面の上を跳ねる道すじが、画面の外へ出ないか（pen_check）。
- B の部品の中にカメラが入らない（camcheck）。粒の列・包み・札が字幕の帯より上に入る（ptcheck）。
- C の町で、窓 → アンテナまでの道すじが建物を通りぬけない。アンテナは画面の幅の 1/20 以上に映る大きさ。
- 03-07 と 08-02 の「光の中へ → 別の舞台」は、白から溶ける 0.7 秒（場面が替わったと分かるように。決まり J-1）。
