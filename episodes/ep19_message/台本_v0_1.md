# まるロボ｜送ったメッセージに乗れたら　台本 v0.1

題：もしも、送ったメッセージに乗れたら？ 相手に届くまでの 0.2 秒を旅してみた（仮）  
想定尺：声で約11分。間と見せ場を入れて約13分（構成案 v1 の 12〜14 分）。  
舞台：A＝まるロボの部屋（朝）／B＝スマホの中（まるロボは部品より小さい）／C＝町の上の空／D＝アンテナの柱の中と、地面の下の管の束／E＝光の線の中（ガラスの管）／F＝携帯の会社の建物・分かれ道の機械と行列／G＝アプリの会社の建物（相手あての箱）／H＝相手の町と、相手のスマホの中／I＝日本の地図の上（引き）  
しかけ：**カメラを切らない 1 本の旅**（S03〜S18）。右上にいつも「いま 0.000 秒」の時計と、小さな「いまここ」の地図（2D）。大きさの変わり目（スマホの中 → 空 → 柱 → ガラスの中）も、寄る・引くでつなぐ。  
時計：0.2 秒で届く場合の目安（03-05 で 1 回ことわる。2026-11-27 ユーザー決定「0.2 秒のまま」）。進み方：包みになる 0.000〜0.010／電波でアンテナへ 〜0.030／携帯の会社の建物 〜0.045／分かれ道と行列 〜0.080／アプリの会社の建物 〜0.110／戻りの光の線・相手のアンテナ 〜0.185／並べ直して開く 〜0.200。  
たとえと本物：包み＝パケット（04-06）、光の線＝光ファイバー（07-07）、道案内の機械＝ルーター（10-08）、相手あての箱＝アプリの会社のコンピューターの中の、届けるのを待つ所（13-03）。本物の名前は 1 回ずつ 2D の札で。あとはたとえの名前だけで呼ぶ。  
名前：包み・札（あて先・送り主・番号）・光る粒・アンテナ・光の線・携帯の会社の建物・道案内の機械・行列・アプリの会社の建物・相手あての箱・鍵・時計。最後までこの呼び方。  
色：まるロボの包み＝青緑（最後まで替えない）、ほかの人の包み＝あたたかい白、写真の包み＝橙、札＝白地に紺の字（2D）。電波の波＝うすい水色の輪、光の線の光＝白。  
守ること：**数字は「例」「ほど」で言う**（0.2 秒・480 文字・2,000 個・20 万 km は条件で変わる）。**アプリ・携帯の会社の名前、本物の画面の見た目は出さない**（既読の印は目の形の絵）。**鍵の話は言い切らない**（「多い」「アプリによってちがう」）。**「ばらばらの道」を言いすぎない**（「ことがある」。短いスタンプは 1 つの包み）。海の底の線は入れない（見送り済み）。似た回の絵と言い回しを使わない（13本目：のれんに吸いこまれる・ベルトの上り下り・分かれ道でピッと押し出す・ジェットコースター／17本目：光の玉が空を飛ぶ）。  
人：友だち（遠くの町に住む人。名前は付けず「友だち」）。喋らない（ナレーターだけ）。  
まるロボ：**喋らない**。字の吹き出しも使わない。腕はないので、包みには体ごとしがみつく（包みの上にお腹をのせ、足をからめる）。気持ちは身ぶり・目の光・電子音と、字のない絵の吹き出し（？・！・物の絵）で出す。  
字：3D の中に字を書かない。時計・札（あて先・送り主・番号）・「パケット」「光ファイバー」「ルーター」・数字（480 文字・20 万 km・0.0025 秒・2,000 個）・帯グラフ・タイトルは全部 2D で、字幕と同じかそれより大きく。メッセージの中身は字のない絵（ネジのスタンプ・まるロボの写真）。  
語尾：ていねいな形のまま、終わりの形を混ぜる。同じ形を 4 本続けない。「しょう」を 2 本続けない。読点は 1 行 2 つまで。「確かめ」は使わない（17本目の決まり）。  
しるし：【確認】＝元の資料で確かめた言い方（資料は最後の表）。  
最初から入れたこと：9本目の直しの要素（`episodes/ep09_escalator/台本の直し_要素.md`：新しい物は 1 場面に 1 つ・見せる → 何か → 問い → 小まとめ・指す言葉・つなぎの言葉）、12本目（冒頭で問いを広げ、新しい疑問を足し、答えを言わないヒントで終える。回収する所で「冒頭の」）、16本目（情報を並べず問いから・「……」のあとの答えは別の台詞・伏線と回収・たとえの「本物では」は 1 文）、17本目（短い言葉で済ませず、だれが何をするか言う）。結果は最後の表。
