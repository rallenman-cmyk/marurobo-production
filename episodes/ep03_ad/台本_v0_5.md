# まるロボ｜会話と広告の回　台本 v0.5

題：さっき話した物が、なぜ広告に出る？ スマホの中で犯人さがし（仮）  
想定尺：ナレーション約3,320字・133本（声で約11分）。間と見せ場を入れて約14〜16分。  
舞台：A＝電車の中・ハルさんの部屋（現実）／B＝スマホの中の町／C＝容疑者の舞台・広告の競りの会場  
人：ハルさん（青い服。広告を見る人）／ソラさん（オレンジの服。友だち）。人の言葉は 2D の吹き出し（声は出さない）。  
容疑者の色（最後まで同じ色で示す）：赤＝①マイク／橙＝②出ていく手がかり／紫＝③わたしたちの記憶（紫のふちの鏡）  
手がかりの荷物（橙の箱）：しずくの印＝いた場所／四角の印＝見たページ／丸2つの印＝一緒にいた人  
しるし：【確認】＝台本を確定する前に、公式の資料で確かめる  
まるロボ：**喋らない**。字の吹き出しも使わない。気持ちは身ぶり・目の光・電子音（ピポ）と、字のない絵の吹き出し（テントの絵・？・！）で出す。アンテナの先が光る＝分かった。探偵の帽子（ハルさんの部屋の、茶色の格子の鹿撃ち帽）をかぶる。運ぶ物は頭に載せる（腕はない）。  
話しかける実験：ナレーターが外からスマホに話しかけ、まるロボは中で見張り番を見る係。  
合言葉：本物の合言葉は**声に出さない**（見ている人のスマホが反応するため）。言う所は「ピー」の音で消し、言葉は 2D の字だけで見せる。似た言葉も同じ。  
字：3D の中には書かない。札・吹き出し・数字は 2D で、字幕と同じかそれより大きく。
