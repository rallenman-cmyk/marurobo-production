# 声の高さをそろえる（3本目 v10）
- `line_pitch.py <声.wav> ../word_times.json`：文ごとの高さ。中央値より 20Hz 以上高い文に「← 高い」。
- `even_pitch.py <入.wav> ../word_times.json <出.wav> [上限 Hz=12] [文ID=上限]`：高い文を中央値＋上限まで下げる（長さは変えない）。2 回通すと残りも下がる。
- `check_shifted.py <元.wav> <直した.wav> ../word_times.json 文ID…`：書き起こしと音のゆがみを AI に聞く。
- v10 の作り方：even_pitch を 2 回（07-05b=18）→ 07-05b は下げると「音の泡も」が聞き取れなくなったので、声を作り直して（4 本作り、224Hz・4.52 秒の 3 本目）同じ長さに縮め、同じ大きさで差し替え（作業フォルダ animatic_tmp/retake_07-05b.wav）。できあがりは animatic_tmp/voice_v10.wav。組み立て（assemble.py）は、あればこれを使う。

# v11（2026-11-20）：機械で高さを下げるのをやめた
- v10 の even_pitch（rubberband で 2〜4 半音下げる）は「声おかしすぎる、スローになってる」と言われたので使わない。
- `retake_batch_lines.py`：高い 31 文が入ったまとめ（batch_XX：5 文ずつ）16 個を、Gemini のバッチ（batchGenerateContent。1 日 100 回の上限とは別）で 4 回ずつ読ませ、1 文ずつに分けて、聞き取り・雑音・高さ（中央値＋18Hz まで）・長さ（元の 0.85〜1.10 倍。長いときだけ 10% まで縮め、短いときは伸ばさず後ろを空ける）で選んで差し替えた。26 文を差し替え、5 文（05-05・07-05b・08-07・22-02・22-02c：驚く・問いかけで、作り直しても同じくらい高い）は元の声のまま。できあがりは animatic_tmp/voice_v11.wav。
- `check_all_lines.py`：全 166 文を 3 回ずつ聞き取らせる（聞き取り・遅い・機械っぽい・抑揚・雑音）。v11 は聞き取り 0.85 未満 0 文・目立つ 0 文。
