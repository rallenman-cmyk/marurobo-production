# まるロボ｜会話と広告の回　構成案 v1（2026-11-12）

仮タイトル：**さっき話した物が、なぜ広告に出る？ スマホの中で犯人さがし**
想定尺：**約15分**（章ごとに増減してよい）

---

## 0．この回のしかけ（一言で）
- **推理もの**にする。「スマホに会話を聞かれた？」という事件を、まるロボが探偵になって調べる。
- 容疑者は 3 人：①マイク（スマホの耳）②出ていく手がかり（行き先・見たページ・一緒にいた人）③わたしたちの記憶。
- 答えは「**犯人は一人じゃなかった**」。マイクは（今わかっている調べでは）無実。手がかりと記憶が組んで、「聞かれた」と感じさせていた。

## 1．面白いポイント
| # | ポイント | なぜ面白いか |
|---|---|---|
| 1 | 誰でも一度は「ゾッとした」体験から始まる | 最初の 10 秒で「あるある」と思える。問いの説明がいらない |
| 2 | 容疑者 3 人を一人ずつ調べる推理もの | 「次は誰？」で最後まで見たくなる。章の区切りがそのまま推理の順番になる |
| 3 | **冒頭の場面に、手がかりが全部映っている**（伏線） | 友だちのスマホのテントの写真、車内のつり広告のテントの絵、季節。あとで巻き戻して「ここに映っていました」と回収する |
| 4 | **見ている人自身が「気のせい」を体験する** | 「冒頭のつり広告に、テントの絵はいくつありましたか？」→ 実は 3 つ。ほとんどの人は覚えていない。気になる物しか目に入らないことを、自分で確かめられる |
| 5 | ページを開いた一瞬で、裏で広告の「競り」が終わっている | 「たった一瞬の間に、こんなことが」という驚き。3D の見せ場になる |
| 6 | **「会話を聞ける」と売っていた会社が、実は聞いていなかった** | 一番の意外な事実。疑いを強めると見せて、最後にひっくり返す |
| 7 | オチはまるロボの自作自演 | テントの広告にまた驚くが、実はまるロボが前の夜にキャンプの動画をずっと見ていた |

## 2．全体構成（約15分）
流れ：**事件 → 容疑者をならべる → ①マイク → ②手がかり → ③記憶 → どんでん返し → 解決 → オチ**

### 冒頭　0:00〜1:30　事件「さっき話したばかりなのに」
- 電車の中（1本目の車両と人を使う）。友だち二人とまるロボ。A「今度、キャンプ行きたいね」B「いいね」。
- **ここで手がかりをしこむ**（目立たせない）：B はスマホでテントの写真を見ている。つり広告にテントの絵が 3 枚。窓の外は紅葉（秋）。
- 夜、A の部屋。スマホを開くと、テントの広告。まるロボがびくっと跳ねる。
- ナレ：「さきほど話したばかりなのに……。まさか、スマホに会話を聞かれていたのでしょうか？」
- 「同じ体験をした人は、とても多いんです」→ タイトル。

### 1章　1:30〜2:30　容疑者をならべる
- まるロボが探偵の帽子（頭に載せる）。容疑者 3 人を 2D の札で並べる：①マイク ②出ていく手がかり ③わたしたちの記憶。
- ナレ：「容疑者は 3 人。まるロボと一緒に、一人ずつ調べてみましょう」。

### 2章　2:30〜5:30　容疑者①マイク「本当に聞いている？」
- **見せ場1**：スマホの画面を通り抜けて中へ。マイクの入り口は、門と見張り番。
- 見張り番は「合言葉」（Hey Siri など）だけを待っていて、それ以外はすぐ忘れる。これはスマホの中だけで起きている。
- **実験**：まるロボが門の前で「テント！」→ 何も起きない。合言葉を言う → 門が開き、画面の上に小さな印が光る（マイクを使うと、画面に印が出る）。
- **調べた結果**：大学の研究で、1万7千本のアプリを調べた。こっそり音を送るアプリは見つからなかった。ただし、画面を撮って送るアプリは見つかった（ここは正直に見せる）。
- ナレ：「今わかっている調べでは、マイクが犯人だという証拠は見つかっていません。では、なぜ当たったのでしょう？」

### 3章　5:30〜10:00　容疑者②出ていく手がかり
- **見せ場2**：スマホから出ていく荷物を追う（1本目の「道と荷物」を使う）。荷物は色と形で見分け、名前は 2D の札で出す。
  - 位置の荷物：いつ、どこにいたか
  - 見たページの荷物：何を見たか
  - 一緒にいた人の荷物：同じ場所・同じ Wi-Fi にいた人
- 荷物が着くのは、広告の「競り」の会場。
- **見せ場3：一瞬の競り**。A がページを開く。その一瞬に、会社たちが「この人に広告を出したい」と札を上げる。一番高い札の広告が画面に出る。ゆっくり再生で見せてから、本当の速さで見せると一瞬で終わる。
- **伏線の回収①**：冒頭を巻き戻す。B は前の日からテントを調べていた。A と B は同じ電車にいた。「一緒にいた人が好きな物」も手がかりになる。
- **伏線の回収②**：窓の外は秋。キャンプの広告が多い季節。「キャンプの話をしたのも、広告が出たのも、同じ理由だったのかもしれません」。
- ナレ：「スマホは耳で聞かなくても、たくさんの手がかりから当ててくるのです」。

### 4章　10:00〜12:30　容疑者③わたしたちの記憶
- **視聴者参加**：「ここで問題です。冒頭の電車に、テントの絵はいくつあったでしょう？」（少し待つ）→ 巻き戻すと 3 枚。「気づいていましたか？」
- まるロボの前に、一日に見る広告がカードの山になって流れてくる。当たった 1 枚だけが光って記憶の箱に入り、外れたカードは消えていく。
- ナレ：「当たった時だけ『聞かれた！』と覚えていて、外れた広告のことは忘れているのです」。（気になりだすと目に入る現象。難しい名前は使わない）

### 5章　12:30〜13:30　どんでん返し「聞いていると言った会社」
- 「でも、本当に『会話を聞いて広告を出せます』と売っていた会社があったんです」→ まるロボが身構える。
- アメリカの取り締まりの役所（FTC）が調べると、**その会社は何も聞いていなかった**。広告主に渡していたのは、よそから買ったメールアドレスの名簿だった。2026 年に処分が決まった。
- ナレ：「聞いていると言った会社でさえ、聞いていなかったのです」。
- 一言そえる：「ただし、本人がちゃんと許していないのに声を集めることは、それだけで問題になる、とも言われました」。

### 6章　13:30〜14:30　解決（まとめ）
- 3 人の容疑者に戻る。①マイク：無実（今わかっている範囲で）。②手がかり：行き先・見たページ・一緒にいた人・季節から、好きそうな物を当てていた。③記憶：当たった時だけ覚えていた。
- 短い区切りで：「耳では聞いていない。でも、行き先は知っている。一緒にいた人も知っている。そして私たちは、当たった時だけ覚えている」。
- 現実に戻る：広告の好みは、スマホの設定で見たり消したりできる（短く。設定の名前は台本の前に確かめる）。

### オチ　14:30〜15:00
- 夜。まるロボがスマホに向かって「テント、テント」とささやく → 何も出ない → ほっとして眠る。
- 朝、テントの広告。まるロボ「！？」
- ナレ：「……昨日の夜、まるロボがキャンプの動画をずっと見ていたことは、内緒にしておきましょう」。

## 3．絵と部品
| 使い回す物 | 新しく作る物 |
|---|---|
| 電車の車両・人・スマホ（1本目） | スマホの中の町（画面を通り抜けた先） |
| 道と荷物・まるロボが運ぶ動き（1本目） | マイクの門と見張り番 |
| 画面を通り抜けて中へ入る動き（QR回） | 広告の競りの会場・札を上げる会社たち |
| | 広告カードの山と記憶の箱・探偵の帽子 |

- 3D の中に字は書かない。つり広告は「テントの絵」だけにする。荷物と容疑者の名前は 2D の札で大きく出す。
- 容疑者 3 人は、最後まで同じ色と形で示す（表し方を途中で変えない）。

## 4．正確さのために気をつけること
- 「絶対に聞いていない」とは言わない。「今わかっている調べでは、証拠は見つかっていない」と言う。
- 手がかりの例（同じ Wi-Fi・一緒にいた場所）は「使われることがある」と言う。どの会社がどれを使うかは決めつけない。
- 競りの速さ（一瞬）・画面に出る印・広告の設定の名前は、台本の前に公式の資料で確かめる。
- 研究は 2018 年のもので、Android のアプリだけを調べた。古さと範囲は台本で一言そえるか決める。

## 5．決めてほしいこと
1. 推理もの（容疑者 3 人）の形でいいか。
2. 冒頭の場所は電車でいいか（1本目の部品が使える。カフェにすると Wi-Fi の話がしやすい）。
3. 見ている人に「テントの絵はいくつ？」と問いかける仕掛けを入れるか。
4. オチ（まるロボの自作自演）でいいか。
