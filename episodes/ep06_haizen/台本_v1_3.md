# まるロボ｜配膳ロボット　台本 v1.3（v8 動画の直し：先輩と呼ぶのは 05-05 から）

> v1.3（2026-11-20、v8 のコメント「ここで急に先輩って当たり前のように呼ぶのおかしい」「ここではじめて先輩という関係性がわかる」）：05-05「まるロボにとっては、先輩のロボットですね」より前は「先輩」と呼ばず「ロボット」に（03-03・05-01）。


題：ファミレスの配膳ロボットは、なぜお客さんにぶつからない？ どの席か分かる？（仮）  
想定尺：ナレーション約3,300字・130本ほど（声で約10分）。間と見せ場を入れて約13分。  
舞台：A＝お昼のファミレス（客席・通路・台所の出口。天井は低めで、目印のシールが小さく並ぶ）／B＝上から見た店の地図（席の点と道）／C＝ロボットの目で見た店（暗い中に、光が当たった所だけ点で浮かぶ）  
人：家族づれ・店員さん・子ども（3本目の人の形）。人も喋らない（ナレーターだけ）。  
先輩：配膳ロボット 1 台。上に画面の顔（丸い目 2 つと口の線）、頭に小さな丸い耳、何段かのトレー、おなかの前にカメラ、足もとの近くで光の物差しが回る。本物のネコの顔はまねしない。先輩も**喋らない**（電子音「ピロン」と、画面の顔と動きだけ）。表情は 3 つ：にこっ・困り顔・怒り顔（簡単な線で）。  
点（最後まで同じ表し方）：止まった物（壁・テーブルの脚）＝青緑の点／動く人の足＝橙の点。席の点（止まる所）＝白い丸。  
しるし：＝台本を確定する前に、元の資料でもう一度確かめる  
まるロボ：**喋らない**。字の吹き出しも使わない。気持ちは身ぶり・目の光・電子音（ピポ）と、字のない絵の吹き出し（？・！・ラーメンの絵）で出す。腕はないので、なでるときは頭をこすりつける。  
字：3D の中には書かない。席の番号・「約 3,000 台」・「70cm」・「3つ」は全部 2D で、字幕と同じかそれより大きく。会社の名前は、すかいらーくグループの台数の所だけ。商品の名前は出さない。
