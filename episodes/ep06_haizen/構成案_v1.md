# まるロボ｜配膳ロボット　構成案 v1（2026-11-14）

仮タイトル：**ファミレスの配膳ロボットは、なぜお客さんにぶつからない？ どの席か分かる？**
想定尺：**約13分**（章ごとに増減してよい）

---

## 0．この回のしかけ（一言で）
- まるロボがファミレスで、**料理を運ぶ先輩ロボット（配膳ロボット）**に出会う。先輩もまるロボも喋らない。ロボット同士は電子音・画面の顔・身ぶり、説明はナレーター（私）。
- 入口の不思議：人でいっぱいの通路を、ラーメンを乗せて走ってくる。**誰にもぶつからない。しかも、ちゃんと注文した席で止まる。**
- **5本目（掃除機）とのちがいをはっきりさせる**（5本目と続けて投稿しないと決めた。2026-11-14）。
  - 5本目：**誰もいない部屋**で、止まっている壁や家具を測って地図を描く。
  - 6本目：**地図はもうある**。主役は「**動く人**」と「**決まった席**」。人は急に止まる・飛び出す・いすを引く。どうよけて、どう届けるか。
  - 光で距離を測る話・地図の上で自分の場所を知る話は、**1 章の中で短く**（この動画だけで分かる長さ。前の回には頼らない）。
- 実験で進める：①まるロボが通路のまん中に立つ ②低い物・高い物を置く ③いすを引いて通路を狭くする ④耳をなでる。一度に変えるのは一つ。

## 2．全体構成（約13分）
流れ：**事件（ぶつからずに届く）→ 先輩に会う → 席が分かる → 遠くを見る（動く人）→ 近くを見る（低い・高い）→ 通れない時 → 顔のひみつ → まとめ → オチ**

### 冒頭　0:00〜1:20　人だらけの通路を、ラーメンが走ってくる
- お昼のファミレス（3本目の人の形を使う）。通路を、家族づれ・店員さん・子どもが行き来する。
- 奥から、トレーにラーメンを乗せた**先輩**がすーっと走ってくる。まるロボは席のそばの通路で、きょろきょろ。
- 先輩がまるロボの前で、**ぴたっ**と止まる。画面の顔が「…？」。まるロボもびくっ。にらめっこ。
- まるロボが動かないので、先輩は少し下がって、**よけて回り道**。そのまま奥の席でぴたりと止まり、ラーメンが届く（客がトレーから取る）。
- ナレ：「人でいっぱいの通路を、ラーメンを乗せて走ってきて、誰にもぶつかりません」
- ナレ：「しかも、ちゃんと、注文した席で止まりました」
- ナレ：「どの席か、どうして分かるのでしょう？ そして、なぜぶつからないのでしょう？」→ タイトル。

### 1章　1:20〜2:20　先輩に会う
- 台所の出口。先輩が戻ってきて待機。まるロボが前へ。電子音であいさつ（まるロボ「ピポ」→ 先輩は画面の顔がにこっ＋「ピロン」）。
- ナレ：「こちらは、配膳ロボット。料理を席まで運ぶ、まるロボの先輩です」
- 先輩の体を一回り：上に画面の顔、何段かのトレー、おなかの前のカメラ、足もとのすき間（ここでは名前だけ。中身はあとの章で）。
- ナレ：「今日は、一緒に先輩について回って、そのひみつを確かめてみましょう」

### 2章　2:20〜4:30　どの席か分かる：地図と「席の点」
- 店員さんが料理をトレーに置き、先輩の画面で**席の番号**を押す（2D で番号を大きく）。
- 上から見た店の絵に切りかえ：店の**地図**。テーブル・通路・台所。それぞれの席のそばに**点**が打ってある（席の点）。
- ナレ：「先輩の中には、この店の地図が入っています。そして、席ごとに、ここで止まる、という点が決めてあるのです」
- 番号を押すと、今いる所から**その点まで道が引かれる**。先輩が走り出す。
- ナレ：「でも、地図の上で、自分がいまどこにいるかは、どうやって分かるのでしょう？」（問い → 短く答える）
  - **天井の目印**：天井に目印のシールを貼っておき、上を向いたカメラでそれを見て、場所を知る機械もあります（実際に、ファミレスの試しで使われた）。先輩がちらっと天井を見上げる絵 → 天井に目印がぽつぽつ光る。
  - もう一つは、まわりの壁やテーブルの形と、地図を見比べるやり方（次の章の光の物差しで）。ここは一言。
- まるロボも天井を見上げる → 首が回りすぎてころん（小さな笑い）。

### 3章　4:30〜6:30　ぶつからない①：遠くを見る ― 動く人（見せ場）
- 先輩の足もと近くで、**光の物差し**がくるくる回る（3D で透かして見せる）。
- ナレ：「足もとの近くでは、光の物差しが回っています。光を当てて、返ってきた光で、まわりの物までの距離を測っているのです」
- **見せ場：ロボットの目で見たファミレス**。画面が暗くなり、光が当たった所だけ点で浮かぶ。壁・テーブルの脚は止まった点（青緑）。**人の足は、歩くたびに動く点**（橙）。
- ナレ：「壁やテーブルは、何度測っても同じ場所にあります。でも、人は、測るたびに場所が変わります」
- ナレ：「先輩は、この動く点を、とくに気をつけて見ているのです」（動く点のまわりに、近づかない丸い範囲が広がる）
- 人の点の前に来ると、先輩は**遅くなる → 止まる → 空いている方へ回る**。冒頭の「ぴたっ」の答え合わせ（冒頭の場面を左上に小さく）。

### 4章　6:30〜8:30　ぶつからない②：近くを見る ― 低い物・高い物（実験）
- ナレ：「でも、ここで一つ、困ったことがあります。回る光は、ある高さの所しか見ていません」（光の面を薄い板で見せる）
- **実験①低い物**：ナレ「では、光の高さより低い物を置いてみましょう」。まるロボが床にころん（光の板の下）。回る光には映らない。……でも先輩は止まる。
- **実験②高い物**：テーブルのはしが、光の板より上に出っぱっている所。先輩はそこも、手前でよける。
- ナレ：「回る光の代わりに、ここを見ているのが、おなかの前のカメラです。会社の説明では、前に 3 つあり、低い所と高い所の物まで、立体で見ています」（カメラの見ている範囲を、上下に広がる扇で）
- **子どもの飛び出し**：テーブルのかげから子どもがぱっと出る → 先輩はすぐ止まる。子どもが行ってから、ゆっくり動き出す。
- **ゆっくり止まる**：止まるとき・曲がるときに、ぐっと止まらず、なめらかに遅くなる。トレーの上のラーメンのスープが、少しゆれるだけ（ここは台本の前に確かめる。確かめられなければ「こぼさないように、ゆっくり」とだけ言う）。

### 5章　8:30〜10:00　通れない時：通路のはば
- **実験③**：ナレ「では、通路を狭くしてみましょう」。客がいすを大きく引く。通路がだんだん狭くなる（はばを 2D の矢印と数字で）。
- 先輩は手前でぴたっ。画面の顔が困り顔。少し待つ。
- ナレ：「会社の説明では、このロボットが通るには、通路のはばが 70cm ほど要ります。それより狭いと、ぶつからないように、止まって待つのです」
- 客がいすを戻す → 先輩の顔がにこっ → 走り出す。まるロボがほっとする。
- ナレ：「どんなにかしこくても、通れないはばはあります。だから、お店の方も、通路を空けておく工夫をしています」（← 資料で確かめる。確かめられなければ前半だけ）

### 6章　10:00〜11:40　顔のひみつ：耳をなでると
- ナレ：「ところで、なぜ先輩には顔があるのでしょう？」
- 顔があると、**何をしているロボットか**が一目で分かり、人が道をあけたり、待ったりしやすくなる、と言われています（← 弱く言う。下の4）。かわいいと、人がやさしくなる、という声も。
- **耳をなでる**：子どもが頭（耳）をなでる → 先輩の顔がうれしそう。
- まるロボもまねして、頭をすりすり（腕がないので）。……しつこくすりすり。→ **先輩の顔が怒った顔に**。まるロボ、びくっと下がる。
- ナレ：「なんと、しつこくなでると、怒った顔になります」
- ナレ：「先輩は、料理を運ぶお仕事中。ずっとなでられていると、仕事に戻れないからだと言われています」（← 資料で確かめる）

### 7章　11:40〜12:30　まとめ
- 問いに戻る：「どの席か、どうして分かるのか」→「店の地図に、席ごとの止まる点が決めてあり、天井の目印や、まわりの形で、自分の場所を確かめながら走っているからです」
- 「なぜぶつからないのか」→「回る光で動く人を見張り、前のカメラで低い物や高い物まで見て、近づくと遅くなって、止まって、よけているからです」
- 「そして、顔があることで、まわりの人も、先輩に道をゆずってくれているのかもしれません」

### オチ　12:30〜13:00
- 台所の出口。まるロボが、ぼんやり先輩のトレーのそばにいる。
- 店員さんが、まるロボをひょいとトレーに乗せる（白くて丸いので、デザートに見えた）。番号をピッ。
- 先輩が走り出す。まるロボはトレーの上で、ぽかん。客席へ運ばれていく。
- ナレ：「……まるロボは、どうやら、デザートだと思われたようです」

## 3．絵と部品
| 使い回す物 | 新しく作る物 |
|---|---|
| まるロボ（1〜5本目） | 先輩（配膳ロボット）：画面の顔・何段かのトレー・前のカメラ。**本物のネコの顔はまねしない**。耳のような形はあってよいが、どこの機械とも言えない顔 |
| 人の形（3本目） | ファミレスの店（通路・テーブル・いす・台所の出口・天井の目印） |
| 光の物差しの見せ方（5本目で作っていれば） | 点で見たファミレス（止まった点＝青緑・動く点＝橙） |
| 4本目の道具一式（組み立て・BGM・点検） | ラーメン・トレー・デザートの皿 |

- 3D の中に字は書かない。席の番号・70cm・「3つ」は全部 2D で大きく重ねる。
- 色は最後まで同じ決まり：止まった物の点＝青緑、動く人の点＝橙。途中で変えない。
- 先輩の顔の表情（にこっ・困り顔・怒り顔）は、まるロボの目の光と見分けられるよう、画面の中の簡単な線で。

## 4．正確さのために気をつけること
- **天井の目印**：天井のシールを読んで走る配膳ロボットは実際にある（ファミレスの試しで使われた。ニュースイッチ https://newswitch.jp/p/28997 ）。ただし**全部の機械ではない**。台本では「〜機械もあります」と言う。冒頭の先輩がどちらかは言い切らない。
- **顔があると人がゆずる**：調べた範囲では、**お店の配膳ロボットで「顔があると人がゆずる」と確かめた研究は見つからなかった**。近いのは、道を走る配達ロボットに顔の表情を付けて、歩く人の反応を見た研究（2024年、大学の構内）と、「かわいさが客のやさしさにつながる」という記事の指摘。台本では「〜と言われています」「〜という声もあります」と弱く言う。言い切らない。
- **耳をなでると喜ぶ・しつこいと怒る**：会社の説明と記事にある（耳や頭にさわると表情と声で反応）。「仕事に戻れないから」という理由は、台本の前に元の記事で確かめる。
- **前のカメラ 3 つ・通路 70cm**：会社の説明。「会社の説明では」を付ける。機種で違う。
- **ゆっくり止まってスープをこぼさない**：台本の前に確かめる。
- **会社・商品・店の名前は出さない**（すかいらーくの台数の話を入れるかは、ここで聞く）。
