# 企画案：ファミレスの配膳ロボットは、なぜお客さんにぶつからない？ どの席か分かる？（2026-11-14）

## 一言で
まるロボがファミレスで、料理を運ぶ先輩ロボット（配膳ロボット）に出会う。人だらけの通路を、なぜぶつからずに、まちがえずに席まで運べるのかを確かめる回。4本目・5本目に続く、ロボットが主役の回。

## 入口の問い
- ネコのような顔のロボットが、ラーメンを運んでくる。どの席に持っていけばいいか、どうして分かるの？
- 子どもが急に飛び出しても、なぜぶつからないの？

## 答え（言いたいこと）
1. **席が分かるのは、店の地図に「席の点」が登録してあるから**：店員さんが画面で席の番号を押すと、ロボットは地図の上のその点まで道を選んで走る。
2. **ぶつからないのは、何重にも見ているから**：くるくる回る光の物差しで遠くの壁や人を、前のカメラ（会社の説明では 3 つ）で、低い物（足もとの子ども・落ちた物）や、高い所に出っぱった物（テーブルのはし）を見る。近づくと遅くなり、止まり、よける。
3. **通れる幅には限りがある**：会社の説明では、通路は 70cm ほど要る。いすが出ていて狭いと通れない。
4. **顔があるのには理由がある**：人が道をゆずってくれる・待ってくれる・子どもが喜ぶ（← 研究や会社の説明で確かめる）。耳をなでると喜ぶが、しつこくなでると怒った顔になる（仕事のじゃまになるから）。
5. **日本のファミレスでは、すかいらーくグループだけで約 3,000 台**が働いている（2022年に導入の方針を発表）。

## 面白いポイント（山場の候補）
| ポイント | なぜ面白いか |
|---|---|
| まるロボが通路のまん中に立つ → 先輩がぴたっと止まって待つ。まるロボがどかないので、先輩が回り道をする | 「ぶつからない」が一目で分かる。ロボット同士のやりとりが笑える |
| 低いまるロボ・飛び出す子ども・テーブルのはし。どれも見えている | 前のカメラが「低い」「高い」を見ている理由が、実験で分かる |
| いすを引いて通路を狭くすると、先輩が通れずに困る | 70cm の決まりが体で分かる |
| 光の物差しで見ると、店の人が「点の集まり」になって動いている | 3D の見せ場。ロボットの目で見たファミレス |
| 耳をなでると喜ぶ → しつこいと怒る | 一番笑える事実。まるロボ（腕がない）が頭でこすりつけて怒られる |
| ラーメンのスープがこぼれない | 止まるとき・曲がるときに、ゆっくり速さを変えている（← 確かめる） |

## 構成のたたき台（約12〜15分）
1. **冒頭**：ファミレス。ネコのような顔のロボットがラーメンを運んでくる。まるロボが通路で前に立つと、ぴたっと止まって待たれる。
2. **問い**：どの席か、どうして分かる？ 人がいっぱいなのに、なぜぶつからない？
3. **席が分かる**：店の地図と「席の点」。店員さんが番号を押す → 地図の上の道。
4. **ぶつからない①遠くを見る**：光の物差しで見たファミレス（人が点の集まり）。
5. **ぶつからない②近くを見る**：前のカメラ。まるロボ（低い）・子ども・テーブルのはしの実験。遅くなる → 止まる → よける。
6. **通れない時**：いすが出て狭い通路。先輩が困って止まる。
7. **顔のひみつ**：顔があるとゆずってもらえる。耳をなでると喜ぶ・怒る。
8. **まとめ**：問い →「〜からです」。
9. **オチの案**：まるロボが先輩のトレーに乗せられ、席まで運ばれる（料理とまちがえられた）／まるロボが耳の代わりにアンテナをなでてもらおうとする。

## 5本目（ロボット掃除機）との違い
- 5本目は「誰もいない部屋の地図を、どう描くか」。6本目は「**人がいっぱいの所を、人をよけて運ぶ**」が主役。地図の話は短くする。
- それでも、この動画だけで分かるようにする（「前の回で見たように」には頼らない）。

## 向いている所
- ロボットが主役（ユーザーの好み）。ファミレスで実物を見た人がとても多い。
- 「耳をなでると怒る」など、笑える事実がある。
- 3本目の人・部屋、5本目の光の物差しの見せ方を使い回せる。

## 気をつける所
- 会社・商品・店の名前は出しすぎない。**本物のロボットの見た目（ネコの顔の画面）をそのまままねしない**。チャンネルの絵で、どこの機械とも言えない顔のロボットにする。台数の話で会社名を出すかは決めてもらう。
- しくみの説明は会社や販売店の宣伝のページが多い。中立の資料でも確かめる。
- 「天井の目印を見て場所を知る」機種もあると言われるが、まだ確かめられていない。確かめられなければ使わない。
- 顔があると人がゆずる、の根拠（研究か会社の説明か）を確かめる。
