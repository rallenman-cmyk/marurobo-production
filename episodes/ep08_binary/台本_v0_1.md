# まるロボ｜0 と 1　台本 v0.1（たたき台）

題：コンピューターは、なぜ 0 と 1 だけで写真も音楽も表せる？（仮）  
想定尺：ナレーション約4,300字・150本ほど（声で約12分半）。間と見せ場を入れて約15分。  
舞台：A＝昼の机の上（スマホ。まるロボの体はスマホの幅の半分くらい）／B＝スマホの中（基板と、頭の部品の中のスイッチの町）／C＝実験の部屋（2 つのランプ・ちらつく天井の明かり）／D＝1945年ごろの大きなコンピューターの部屋（真空管の列）／E＝写真の拡大（点 → 3 つの光 → 0 と 1）／F＝音の波（空気の波・測る棒・階段）  
スマホ：チャンネルの絵で描く（どこの会社の物とも言えない形）。会社や商品の名前は出さない。  
スイッチ：明かりがつく＝1（明るい黄色）、消える＝0（暗い灰色）。最後までこの色。  
人：昔のコンピューターを動かす人たち・指で数える手（3本目の人の形）。人も喋らない（ナレーターだけ）。  
しるし：【確認】＝台本を確定する前に、元の資料でもう一度確かめる  
まるロボ：**喋らない**。字の吹き出しも使わない。腕はないので、スイッチは跳ねて乗って切りかえる。気持ちは身ぶり・目の光・電子音（ピポ）と、字のない絵の吹き出し（？・！・物の絵）で出す。  
字：3D の中には書かない。0 と 1・数字・年は全部 2D で、字幕と同じかそれより大きく。長い 0 と 1 の列は「流れる模様」として見せ、読ませる所だけ大きく短く。  
語尾：ていねいな形のまま、終わりの形（です・ます・ました・のです・ですね・でしょうか・ましょう など）を混ぜる。同じ形を 4 本続けない。
