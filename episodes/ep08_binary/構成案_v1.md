# まるロボ｜0 と 1　構成案 v1（2026-11-15）

仮タイトル：**コンピューターは、なぜ 0 と 1 だけで写真も音楽も表せる？**
想定尺：**約13〜14分**（章ごとに増減してよい）

## 0．この回のしかけ（一言で）
- まるロボが、**自分で撮った自分の写真**をどんどん拡大していく → 色の点 → 数字 → 0 と 1 の列。「写真が 0 と 1」が目で分かる所から始める。
- そのまま**スマホの中の、小さなスイッチの町**へ入る。スイッチは「ついている＝1」「消えている＝0」だけ。
- 入口の不思議は 2 つ：①たった 2 つで、なぜ色や音まで表せる？ ②そもそも、なぜ 0〜9 の 10 個ではなく 2 つだけ？
- **②を先に実験で**：10 段階のランプと 2 段階のランプを、ちらつく部屋で読む → 10 段階だけ読みまちがえる。「だから 2 つ」が体で分かってから、①（数 → 色 → 音）へ進む。
- 流れは「事件（写真が 0 と 1）→ スイッチの町 → なぜ 2 つ？（実験）→ 昔は 10 個・3 個もあった → 2 つで数を書く（指で数える）→ 色 → 音 → 意外な弱点 0.1＋0.2 → まとめ → オチ」。
- 強い先（同じ問いの 3D 解説・509万回）との違い：**自分の写真が入口・まるロボの実験・見ている人が指で数える・0.1＋0.2・日本語の言い方**。中のスイッチのくわしいしくみ（電子の動き）には深入りしない。
- 2本目（QR）を見ていなくても分かるように、「8 こで 1 組」はこの回の中で一から見せる。

## 2．全体構成（約13〜14分）
流れ：**事件（写真が 0 と 1）→ スイッチの町 → なぜ 2 つ？ → 昔の機械 → 数 → 色 → 音 → 0.1＋0.2 → まとめ → オチ**

### 冒頭　0:00〜1:20　自分の写真を、拡大していくと……
- 机の上のスマホ（どこの会社の物とも言えない形）。まるロボが体当たりでシャッターを押し、自撮り。カシャ。
- 撮れた写真を見て、得意げ。もっとよく見ようと、画面に近づく → 拡大。
- 拡大していくと、目のレンズが**四角い色の点**の集まりになる。さらに近づくと、1 つの点に**3 つの数**（2D）。さらに近づくと、数が **0 と 1 の列**になって流れ出す。まるロボ、びくっ（「！」の吹き出し）。
- ナレ：「写真をどんどん拡大すると……なんと、0 と 1 の列になってしまいました」
- ナレ：「スマホの中では、写真も、音楽も、全部 0 と 1 でできていると言われます」
- ナレ：「たった 2 つの記号で、どうして色や音まで表せるのでしょう？　そもそも、なぜ 2 つだけなのでしょう？」→ タイトル。
- ナレ（引き）：「途中で、あなたの指でも、0 と 1 を数えてみます。そして最後に、コンピューターが苦手な、意外な計算もお見せします」（離脱を防ぐ予告）

### 1章　1:20〜2:50　スマホの中の、スイッチの町
- まるロボがスマホの中へ吸いこまれる。基板の上 → 頭の部品（黒い四角）の中へ。
- 上空から見下ろす：小さなスイッチが、町のように、どこまでも並んでいる。
- 1 つのスイッチの前へ：電気が流れると明かりがつく＝**1**、流れないと消える＝**0**（2D で「1」「0」を真上に）。まるロボが乗ると、ぱちっと切りかわる。
- ナレ：「スマホの頭の部品には、こんなスイッチが、なんと 100 億こ以上も入っています」（2D「100億こ以上」）
- ナレ：「でも、一つ一つは、ついているか、消えているか。それだけです」
- 橋：「なぜ、もっとたくさんの段階にしないのでしょう？　たとえば、0 から 9 まで、10 段階の明るさにすれば、1 つで 10 通り表せるのに」

### 2章　2:50〜4:40　実験：10 段階と 2 段階、どっちがまちがえない？
- まるロボの前に、ランプが 2 つ：**10 段階**で明るさを変えるランプ（数字は 0〜9）と、**2 段階**（ついた・消えた）のランプ。
- ①静かな部屋：まるロボが明るさを読む。10 段階「6」、2 段階「1」。どちらも正解。
- ②一つだけ変える：部屋の電気が**ちらつく**（スイッチの町は電気がゆれる、のたとえ）。
  - 10 段階：「6」が「5」にも「7」にも見える。まるロボ、首をかしげる（「？」）。→ 読みまちがえ（2D で×）。
  - 2 段階：ちらついても、「ついている」は「ついている」。→ 正解（2D で○）。
- ナレ：「段階が多いと、少しゆれただけで、となりの数とまちがえてしまいます。ついたか、消えたかの 2 つなら、ゆれても、まちがえません」
- ナレ：「何億回、何兆回と計算するコンピューターにとって、一度もまちがえないことは、とても大事なのです」

### 3章　4:40〜6:00　こぼれ話：昔は 10 個も、3 個もあった
- ナレ：「ただし、最初から 2 つだったわけではありません」
- 1945年ごろのアメリカ。部屋いっぱいの大きなコンピューター（真空管という電球のような部品がずらり。実物のまねでない形）。
- **意外な話①**：この機械は、私たちと同じ **0〜9 の 10 個の数字**で計算していた。1 けたを覚えるのに、真空管が 36 本。まるロボが 1 けた分の列の前を歩いて、長さにあきれる。
- **意外な話②**：1958年、モスクワの大学では、**3 つの記号**で動くコンピューターが作られた（約 50 台）。
- ナレ：「それでも、いまのコンピューターは、ほとんどが 2 つにそろいました。まちがえにくく、作りやすかったからです」
- 橋：「では、0 と 1 の 2 つだけで、どうやって 2 や 3、もっと大きな数を書くのでしょう？」

### 4章　6:00〜8:00　2 つで数を書く：指で数えてみよう
- スイッチを 1 列に 5 こ並べる。右から「1・2・4・8・16」の重さ（2D で上に書く）。
- ついたスイッチの数を足す：「1」→ 1、「1 と 2」→ 3、……全部つくと 31。まるロボがスイッチの上を跳ねて、つけたり消したり。
- ナレ：「右のスイッチは 1、そのとなりは 2、その次は 4。一つ左へ行くごとに、2 倍になります」
- **見ている人も参加**：手の指 5 本をスイッチにする（3D の人の手。のばす＝1、折る＝0）。
  - ナレ：「あなたも、片手を出してみてください」→ 1、2、3 を指で。最後に全部のばして 31。
  - ナレ：「両手を使えば、1023 まで数えられます」
- **8 こで 1 組**：スイッチ 8 こで、0〜255 の 256 通り。ここが次の色の話の下地（ここで一から見せる）。
- 文字は一言だけ：「A」は 65 番、と決めた番号の表があり、文字も数として 0 と 1 にできる（2D で「A＝65＝01000001」）。

### 5章　8:00〜9:30　色：3 つの数で、約 1,677 万色
- 冒頭の写真の、1 つの点へ戻る。点は**赤・緑・青**の 3 つの光でできている（3D で 3 色の小さな光が重なる）。
- それぞれの明るさを、8 こ 1 組のスイッチで 0〜255 の 256 段階に。
- まるロボの目の青緑：赤は少し、緑と青はたくさん（2D で 3 つの数。台本で目の色の実際の数を入れる）。
- ナレ：「256 × 256 × 256。なんと、約 1,677 万通りの色が表せます」
- ナレ：「写真 1 枚には、この点が 1,200 万こほど。0 と 1 にすると、約 3 億こになります」（2D）

### 6章　9:30〜11:00　音：1 秒に 44,100 回、測る
- まるロボが電子音「ピポ」を鳴らす → 空気の波（3D の波）。
- 波を、細い棒で何度も測る：測った高さを数にする → 波が**細かい階段**になる（2D）。
- ナレ：「CD の音楽では、1 秒間に 44,100 回、音の高さを測ります」
- 高さも細かく：65,536 段階（スイッチ 16 こ）。
- 階段を少なくする（測る回数を減らす）と、まるロボの「ピポ」がガサガサの音に → もとに戻すと、なめらか（条件を一つ変える）。
- ナレ：「細かく測るほど、もとの音に近づきます。こうして、音楽も 0 と 1 の列になるのです」

### 7章　11:00〜12:30　意外な弱点：0.1＋0.2
- ナレ：「何でも表せる 0 と 1。でも、実は、苦手な数があります」
- 画面に「0.1 ＋ 0.2 ＝」。コンピューターの答え：**0.30000000000000004**（2D で大きく。最後の 4 を光らせる）。
- まるロボ、目が点に（「？」）。
- 問い → 正体：
  - ナレ：「私たちも、1 ÷ 3 を小数で書くと、0.333……と、どこまでも続いて、ぴったり書けません」
  - ナレ：「コンピューターにとっての 0.1 も、それと同じ。0 と 1 で書くと、0.000110011……と、どこまでも続いてしまうのです」（2D で続く列）
  - スイッチの数には限りがあるので、途中で切る → ほんの少しずれる → 足すと、ずれが見えてしまう。
- ナレ：「ふだん使う電卓やアプリは、このずれが見えないように工夫しています。だから、ふだんは気づかないのです」

### 8章　12:30〜13:20　まとめ
- 問いに戻る：「コンピューターは、なぜ 0 と 1 だけで、写真も音楽も表せるのか」
- →「まちがえにくい『ついた・消えた』のスイッチを、ものすごい数並べて、数を書くからです。色は 3 つの数、音は 1 秒に 44,100 こ の数。数にできるものは、全部 0 と 1 で表せるのです」
- 冒頭の写真に戻る：拡大を逆に → 0 と 1 → 数 → 色の点 → まるロボの写真。

### オチ　13:20〜14:00　0 と 1 の「ありがとう」
- まるロボが画面のこちらを向く。目の光が、ついた・消えた・ついた……とまたたく（電子音つき）。
- 字幕のかわりに、下に 0 と 1 の列が流れる（2D）→ 最後に「ありがとう」に変わる。
- ナレ：「……まるロボなりの、ごあいさつのようです」

## 3．絵と部品
| 使い回す物 | 新しく作る物 |
|---|---|
| まるロボ・跳ぶ動き・足音・電子音（1〜7本目） | スマホ（どこの会社とも言えない形）・中の基板と頭の部品 |
| 人の形・手（3本目〜） | スイッチの町（明かりのつく小さなスイッチがずらり。上空の引きも） |
| 4〜7本目の道具一式（組み立て・BGM・点検） | 10 段階と 2 段階のランプ・ちらつく部屋 |
| | 1945年ごろの大きなコンピューター（真空管の列） |
| | 写真の拡大（点 → 数 → 0 と 1）・音の波と階段 |

- **3D の中に字を書かない**（決まり）。0・1・数字は全部 2D で重ねる。0 と 1 の列は、スマホで読める大きさで**短く**（長い列は「流れる模様」として見せ、読ませる所だけ大きく）。
- 色の決まり：1＝明るい黄色の光、0＝暗い灰色で最後までそろえる。赤・緑・青は 5章だけで使う。
- 実在の会社・機械の形をまねない。名前は出さない（「1945年ごろの大きなコンピューター」「モスクワの大学」）。

## 4．正確さのために気をつけること（2026-11-15 に元の資料で確かめた）
- **スイッチの数**：スマホの頭の部品で、会社が出した数は 190 億（2023年）。ほかの会社の物も 100 億こをこえる → 「100 億こ以上」と言う。
- **10 個の数字の機械**：1945年ごろの ENIAC。0〜9 の 10 進数で計算し、1 けたに真空管 36 本（うち 10 本で「いま何か」を覚える輪）。全体は 1 万 7 千本ほど（数え方で 2 万本とも）→ 全体の本数は言わない。
- **3 つの記号の機械**：1958年の終わりにモスクワの大学で完成（セトゥニ）。作られたのは約 50 台。「よく動いた」は資料にあるが、台本では言いすぎない。
- **ランプの実験**：「段階が多いとゆれに弱い」の**たとえ**。実際のスイッチの電気のゆれの数字は出さない。
- **指で数える**：5 本で 0〜31、10 本で 0〜1023（2⁵−1、2¹⁰−1）。
- **文字**：「A」＝65＝01000001（コンピューターで広く使われる番号の表）。「あ」は 12354 番で、0 と 1 は 24 こ使う。台本では「A」だけにする。
- **色**：赤・緑・青を 8 こずつ（256 段階）→ 16,777,216 通り＝約 1,677 万色。
- **写真の 0 と 1 の数**：1,200 万の点 × 24 ＝ 2 億 8,800 万 ≒ 約 3 億こ（縮める前の数。保存するときは小さく縮めている、と台本で一言そえるか決める）。
- **音**：CD は 1 秒に 44,100 回・16 こ（65,536 段階）。左右 2 つ分あるが、台本では言わない。
- **0.1＋0.2**：ふつうのやり方（64 こ使う小数）で計算すると 0.30000000000000004（Python で確かめた）。0.1 は中では 0.1000000000000000055511…と、ほんの少し大きい。**電卓やエクセルは 0.3 と表示する**ので、「電卓で試すと、ずれます」とは言わない。見せるのは「プログラムで計算すると」の画面。
