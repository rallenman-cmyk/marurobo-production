# 企画案：ロボット掃除機は、どうやって部屋の形を覚える？（2026-11-14）

## 一言で
まるロボが、先輩のロボット（ロボット掃除機）について回り、「見たこともない部屋の地図を、どうやって描くのか」を確かめる回。4本目に続き、ロボットが主役の回。

## 入口の問い
- 掃除が終わると、スマホに部屋の地図が出てくる。誰も教えていないのに、どうやって描いたの？
- しかも、地図の中で「今どこにいるか」まで分かっている。

## 答え（言いたいこと）
1. **昔の先輩は、地図を持っていなかった**：2002年の最初のころの機械は、まっすぐ進んで、ぶつかったら向きを変えるだけ（ぐるぐる・壁ぞい・ななめ横切りを組み合わせる）。
2. **今の先輩は、走りながら地図を描き、同時に自分の場所を探している**：目かくしで知らない部屋を歩き、手でさわった壁を紙に描いていくのに近い。
   - 「地図を描くには自分の場所が要る。自分の場所を知るには地図が要る」の、にわとりと卵。→ 両方を少しずつ同時に直していく。
   - 車輪が何回まわったかで「だいたいここ」→ 壁の形と見比べて「ぴったりここ」に直す。
3. **見る方法は 2 通り**
   - 頭の上の丸いふたの中で、光の物差しがくるくる回り、壁や家具までの距離を何度も測る。測った点が床に並んで、部屋の形になる。
   - カメラで、天井や家具の角を「目印」にする。暗い所は苦手。
4. **ほかの感じ方**：おなかの下の光で段差を見る（光が返ってこない＝がけ → 止まる）／前のバンパーでぶつかったことを知る。

## 面白いポイント（山場の候補）
| ポイント | なぜ面白いか |
|---|---|
| まるロボが目の光を消して、昔の先輩と同じ「ぶつかって曲がる」をやってみる | 部屋のすみが残る・同じ所を何度も通る。地図があるありがたさが体で分かる |
| 光の物差しが回るたびに、床に点がふえて部屋の形が浮かび上がる | 3D の一番の見せ場。何もない暗い床に、点で部屋が描かれていく |
| にわとりと卵（地図と自分の場所） | 一番の「なるほど」。両方を少しずつ直す様子を、ずれた地図がぴたっと合う絵で見せる |
| 電気を消すと、カメラの先輩は迷子になる | 実験で「暗いと苦手」を見せられる |
| 段差の手前でぴたっと止まる先輩、落ちるまるロボ | ドジのまるロボらしい笑い |
| ペットのうんちをよける約束（よけられなかったら新品と取りかえる、と約束した会社がある） | 一番笑える事実。カメラと AI で「よける物」を見分けている話につながる |

## 構成のたたき台（約12〜15分）
1. **冒頭**：掃除が終わると、スマホに部屋の地図。まるロボがびっくり。「誰も教えていないのに？」
2. **先輩に会う**：ロボット掃除機（先輩）とまるロボのあいさつ（電子音どうし）。
3. **昔の先輩**：まるロボが目の光を消して、ぶつかって曲がるだけで部屋を回る実験 → すみが残る。
4. **今の先輩①光の物差し**：回る光で点が描かれ、部屋の形が浮かぶ（見せ場）。
5. **今の先輩②自分はどこ？**：にわとりと卵 → 車輪の回数で「だいたい」→ 壁の形で「ぴったり」。
6. **カメラの先輩**：天井の角を目印に。電気を消すと迷子。
7. **落ちない・よける**：段差の光（まるロボは落ちる）、うんちをよける約束。
8. **まとめ**：問い →「〜からです」。
9. **オチの案**：先輩の地図を見ると、まるロボが「動かない家具」として描かれている／まるロボが先輩の上に乗って帰る（ネコが乗るあの動画のように）。

## 向いている所
- ロボットが主役（まるロボの仲間）で、ユーザーの好み（4本目・5本目）に合う。
- 家にある・見たことがある機械で、「地図が出る」不思議が誰にでも伝わる。
- 3D の見せ場（点で部屋が描かれる・光の物差し）が大きい。
- 3本目の部屋・人、2本目のマスの床などが使い回せる。

## 気をつける所
