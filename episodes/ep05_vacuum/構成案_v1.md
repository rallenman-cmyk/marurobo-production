# まるロボ｜ロボット掃除機　構成案 v1（2026-11-14）

仮タイトル：**ロボット掃除機は、どうやって部屋の形を覚える？**
想定尺：**約14分**（章ごとに増減してよい）

---

## 0．この回のしかけ（一言で）
- まるロボが、**先輩のロボット（ロボット掃除機）**について回る。先輩もまるロボも喋らない。ロボット同士は電子音と身ぶり、説明はナレーター（私）。
- 入口の不思議：掃除が終わると、スマホに部屋の地図が出る。**誰も部屋の形を教えていないのに**、どうやって描いたの？　しかも「今どこにいるか」まで分かっている。
- 実験で進める：①まるロボが目の光を消して、昔の先輩と同じ「ぶつかったら曲がる」をやる → すみが残る ②今の先輩について回る → 暗い床に点がふえて部屋が浮かぶ ③条件を一つ変える（じゅうたんで車輪がすべる・電気を消す・段差）。
- 流れは「昔（地図なし）→ 今（地図を描く）→ 地図を描くための一番の難しさ（自分はどこ？）→ 見る方法のもう 1 つ（カメラ）→ 落ちない・よける」。

## 2．全体構成（約14分）
流れ：**事件（地図が出る）→ 先輩に会う → 昔の先輩（地図なし）→ 光の物差し（見せ場）→ 自分はどこ？ → カメラの先輩 → 落ちない・よける → まとめ → オチ**

### 冒頭　0:00〜1:20　誰も教えていないのに、地図が出た
- 昼の部屋（3本目のハルさんの部屋を使う）。先輩（ロボット掃除機）が掃除を終えて、台に戻る。「ピロリン」。
- 床に置かれたスマホが光る。画面に**部屋の地図**（2D で大きく。ソファ・机・ベッドの形まで）。まるロボがのぞきこんで、びくっ。地図と部屋を何度も見比べる。
- ナレ：「掃除が終わると、スマホに部屋の地図が出てきます。でも、この部屋の形を、誰も教えていません」
- ナレ：「しかも、地図の中には、いま先輩がいる場所まで、点で出ています」（地図の上の点が光る → 台の上の先輩）
- ナレ：「見たこともない部屋の地図を、いったい、どうやって描いたのでしょう？」→ タイトル。

### 1章　1:20〜2:20　先輩に会う
- まるロボが先輩の前へ。電子音であいさつ（まるロボ「ピポ」→ 先輩「ピッ、ピッ」）。先輩のほうが低く、短い音（キャラの違い）。
- ナレ：「こちらは、ロボット掃除機。まるロボにとっては、先輩のロボットです」
- ナレ：「今日は、一緒に先輩について回って、地図の描き方を確かめてみましょう」
- 先輩の体を一回りして見せる：頭の上の丸いふた・前のバンパー・おなかの下（ここでは名前だけ。中身はあとの章で）。

### 2章　2:20〜4:30　昔の先輩：ぶつかったら曲がるだけ（実験①）
- ナレ：「その前に、昔の先輩は、どうしていたのでしょう？」（話の役目の言葉）
- 2002年ごろのロボット掃除機は、**地図を持っていなかった**。まっすぐ進んで、ぶつかったら向きを変える。ぐるぐる回る・壁にそって進む・部屋をななめに横切る、を組み合わせていた。
- **実験①**：ナレ「では、まるロボにも、同じやり方でやってみてもらいましょう」。まるロボが**目の光を消す**（何も見えない合図）。
  - まっすぐ進む → ゴン（バンパーの代わりに体で）→ 向きを変える → ゴン……。
  - 通った跡を床に線で残す（上から見た引きの絵）。同じ所を何度も通る。**すみが残る**。
- ナレ：「何度も同じ所を通るのに、すみには一度も行けていません」
- ナレ：「では、今の先輩はどうでしょう？」（橋）

### 3章　4:30〜7:00　今の先輩①：光の物差しで、点を描く（見せ場）
- 頭の上の丸いふたの中で、**光の物差しがくるくる回る**（3D でふたを透かして見せる）。
- ナレ：「頭の上のこのふたの中では、光の物差しが回っています。光を当てて、返ってきた光で、壁や家具までの距離を測っているのです」
- **見せ場**：部屋の明かりが落ち、暗い床だけになる。先輩が少し進むたびに、光が当たった所に点がぽつぽつ並び、**壁・ソファの足・机の形が点で浮かび上がる**。まるロボが後ろについて歩き、点がふえるたびに目を見開く。
- 1 回転で、ぐるりと何百もの点（数字は台本の前に確かめる）。それを何度もくり返す。
- 最後に点がつながって、冒頭のスマホの地図と同じ形に重なる（冒頭の地図を小窓で）。
- ナレ：「こうして測った点を、つないでいったものが、あの地図だったのです」

### 4章　7:00〜9:30　今の先輩②：自分は、どこにいる？（一番の「なるほど」）
- ナレ：「でも、ここで一つ、困ったことがあります」
- 点を正しい場所に置くには、**測ったとき自分がどこにいたか**が分かっていないといけない。
- ところが、自分がどこにいるかを知るには、**地図**が要る。
- ナレ：「地図を描くには、自分の場所が要る。自分の場所を知るには、地図が要る。まるで、にわとりと卵のようです」（にわとりと卵の絵がくるくる回る吹き出し。まるロボの頭の上）
- 答え：**両方を、少しずつ同時に直していく**。
  - まず「車輪が何回まわったか」で、だいたいここ、と見当をつける（車輪に回った数を 2D で）。
  - 次に、いま見えている壁の形を、これまでの地図と見比べて、「ぴったりここ」に直す。
- **実験②**：先輩が**じゅうたん**の上へ。車輪がすべって空回り → 車輪の数では進んだことになっているのに、本当は進んでいない。地図の点がずれて、壁が二重になる。まるロボ、首をかしげる。
- 先輩が部屋を一周して、**最初に見た壁**に戻ってくる → 「あ、ここ知ってる」と気づいて（先輩の目の光がピッ）、ずれた地図が**ぴたっと重なる**。
- ナレ：「前に見た場所に戻ってきたことに気づくと、それまでのずれを、まとめて直せるのです」

### 5章　9:30〜11:00　カメラの先輩：目印で場所を知る（実験③）
- ナレ：「また、先輩の中には、光の物差しではなく、カメラで見ているものもいます」
- 2 台目の先輩（頭にふたがなく、前にカメラの目。色で違いが分かる形）が登場。まるロボは 2 台を見比べる。
- カメラの先輩は、天井の角・照明・家具の角を**目印**にして、自分の場所を知る（目印に小さな光の印。見えた目印どうしを線で結ばない＝つながりは「同時に光る」で）。
- **実験③**：ナレ「では、部屋の電気を消してみましょう」→ まっ暗。光の物差しの先輩はそのまま進む。カメラの先輩は目印が見えず、その場でくるくる → **迷子**。まるロボが目の光で照らしてあげる（目印がもう一度見えて、動き出す）。
- ナレ：「カメラは、人の目と同じで、暗い所が苦手なのです」（ライトで照らす機械もあることは一言）

### 6章　11:00〜12:40　落ちない・よける
- **段差**：階段の手前。先輩はぴたっと止まって向きを変える。まるロボはそのまま進んで、**落ちる**（下でころん）。
  - ナレ：「先輩のおなかの下にも、光があります。下へ光を当てて、返ってこなければ、そこはがけ。だから止まれるのです」
- **よける物**：床に靴下とコード。カメラの先輩は手前でよける。
  - ナレ：「カメラで見て、それが何かを見分けて、よけているのです」
  - **うんちの約束**：ナレ「なんと、ペットのうんちをよけられなかったら、新品と取りかえます、と約束した会社まであります」（2021年。犬のうんちの絵は、かわいい絵文字くらいに。2D の字で「約束」）。まるロボ、思わずのけぞる。

### 7章　12:40〜13:30　まとめ
- 問いに戻る：「見たこともない部屋の地図を、どうやって描いたのか」
- →「光の物差しやカメラで、まわりを何度も測りながら、地図を描くのと、自分の場所を探すのを、同時に少しずつ直していたからです」
- 「昔は、ぶつかって曲がるだけだった先輩は、今では、自分で地図を描けるようになっていたのです」

### オチ　13:30〜14:00
- 掃除が終わり、スマホにまた地図。まるロボがのぞきこむと、地図の真ん中に**丸い形の「動かない物」**。
- まるロボが、地図と自分を見比べる。……ずっと、同じ場所で見ていたから。
- ナレ：「……先輩の地図では、まるロボは、家具だと思われていたようです」
- （もう一つの案：まるロボが先輩の上に乗って、台まで帰る。下の「決めてほしいこと」）

## 3．絵と部品
| 使い回す物 | 新しく作る物 |
|---|---|
| まるロボ（1〜4本目） | 先輩（ロボット掃除機）2 台：光の物差しの先輩・カメラの先輩。どこの製品とも言えない形と色 |
| ハルさんの部屋・人の形（3本目） | 光の物差しの回る光・床に並ぶ点・点がつながる地図 |
| マスの床（2本目） | 充電の台・じゅうたん・階段の段差・靴下・コード |
| 4本目の道具一式（組み立て・BGM・点検） | にわとりと卵の吹き出し（字のない絵） |

- 3D の中に字は書かない。年（2002年・2021年）・「約束」・車輪の数は全部 2D で大きく重ねる。
- 点は最後まで同じ表し方（光が当たった所＝青緑の点）。途中で線や面に変えない（つながるときは点が並んだまま線になる）。
- 冒頭の地図・3章の点の地図・オチの地図は、同じ形・同じ色にそろえる。
- 「暗くする」場面（3章の見せ場・5章の実験）は、何が起きたか分かるように、暗くする前に部屋の全体を一度見せる。

## 4．正確さのために気をつけること
- **測り方は言い分けない。** 光の物差しには「光が返るまでの時間で測る物」と「返ってきた光の位置で測る物」がある。台本では「光を当てて、返ってきた光で距離を測る」とだけ言う。
- **会社・商品の名前は出さない。** 「2002年ごろの、最初のころのロボット掃除機」「ある会社」。
- **2002年の先輩のやり方**（ぐるぐる・壁ぞい・ななめ横切り／バンパー／おなかの下の段差の光）は、台本の前にもう一度、中立の資料で確かめる。
- **地図と自分の場所を同時に直す話**は、中立の資料で確かめた（MathWorks の解説：車輪などで出す場所は少しずつずれがたまる。前に来た場所に戻ったと気づくと、ずれをまとめて直す。ロボット掃除機の例も出ている）。台本ではむずかしい名前（SLAM など）は使わない。
- **うんちの約束**：会社の約束のページで確かめた中身 → 対象は犬・猫の固いうんち、買ってから 1 年（国によって、決まった機種・期間だけ）、よける機能を入れていることが条件。**「今もやっている」とは言わない**。「2021年に、ある会社が約束しました」と過去の話として言う。
- 1 回転の点の数・回る速さは、機械で違う。入れるなら台本の前に資料で確かめ、「数百」くらいにぼかす。
- カメラで家の中を撮ることへの心配は、触れるなら一言だけ（決めてほしいこと 4）。

## 5．決めてほしいこと（質問の画面で聞く）
1. 先輩を 2 台（光の物差し・カメラ）にするか、1 台にするか。
2. オチ：「家具だと思われていた」か「先輩に乗って帰る」か。
3. うんちの約束を入れるか。
4. カメラで家の中を撮る心配に触れるか。
