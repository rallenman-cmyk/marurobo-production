## 共通の決まり（どの動きでも）
- 首がない。うなずく・首を振る・かしげるは、胴ぜんぶ（重い体）で表す。
- 目が先、体があと：目が先に跳び（約 0.1 秒）、0.12 秒遅れて胴が追う。胴が追いつくと目は真ん中へ戻る。
- 何かが起きてから反応するまで 0.2 秒の遅れを入れる（驚く・よろける）。
- 動きはなめらかに始まり、なめらかに止まる（躍度最小）。大きい動きの前には予備動作（体重を移す・しゃがむ）。
- 重さがある：加速・減速の分だけ体が傾く。着地は脚で受け止める。アンテナはばねで揺れる。運ぶ荷物も少し揺れる（2.2Hz）。
- いつも生きている（止まっている間も）：息で上下に ±8mm（4 秒に 1 回）、まばたき 3〜5 秒ごと（閉じる 2 コマ・止める 1 コマ・開く 4 コマ）、4〜7 秒ごとの体重移動（左右 1.2cm・1.2°）、目の小さな動き。→ 何もしない間は `idle()` を入れる。
- 気持ちは 4 つで出す：体（傾き・沈み・跳ね）、目（輪の開き・内側の輪の動き・レンズを前へ出す）、アンテナの光（点滅・ふくらむ・落とす）、電子音。
- 動きにはそれぞれ音が決まっている（下の「音」）。3D と同じ予定の `p.events` の時刻に置く。

- 共通の部品（2026-11-17、3〜6本目の描き直しで作った）：`scripts/maru_real.py`（本物のまるロボ＝story.blend を置き、毎コマを marurig で当てる。クラウドの確認は同じ部品名・同じ寸法の代わりの体）、`scripts/maru_cmds.py`（前の回と同じ「声の時刻で mr.walk / at / surprise …」の書き方を、時刻の順に Plan に並べる。この一覧の部品は `mr.<部品名>(t, …)` で全部呼べる。間に合わない動きは `LATE` に出る）。

## 動きの一覧
### 待つ・見る・向く
| 部品 | 見た目 | 使う場面 |
|---|---|---|
| `idle(秒)` | 呼吸・体重移動・目の小さな動き | 何もしない間（立っているだけにしない） |
| `look(yaw, pitch)` | 目が先に跳び、胴があとから向く（左が＋・上が＋） | 物を見る・話している所を見る |
| `look_around()` | 左右を見回す | 新しい場所に来たとき |
| `turn_to(度)` | 目 → 胴 → 足踏み（片足 35° まで）で向きを変える | 向きを変える（体ごと回さない） |

### 移動（くわしくは `maru_walk.md`）
| 部品 | 見た目 | 音 |
|---|---|---|
| `walk_to((x, y), speed=1.0)` | 体重を移してから歩き出し、両足をそろえて止まる | 一歩ずつ step |
| `run_to((x, y))` | 走り（2.0m/s、宙に浮く間あり） | step |
| `back_to((x, y))` | 左の肩ごしに後ろを見て、小さな足踏みで下がる | step_turn |
| `jump_to((x, y), z1=高さ)` | 見る → 向く → 深くしゃがむ（0.36 秒）→ 蹴る → 放物線 → 脚で受け止める。台に跳び乗る（30cm・1.2m 先）・跳び降りる（着く速さ 約 3m/s を受け止める） | takeoff・land |

### 気持ち
| 部品 | 見た目 | 使う場面 | 音 |
|---|---|---|---|
| `nod(n=2, amp=8)` | 胴ぜんぶで下げて（0.2 秒）ゆっくり戻す（0.28 秒）。2 回目は小さく | はい・そうそう | beep_yes |
| `shake(amp=12)` | 胴を左右に 12° ひねる → だんだん小さく | いいえ・ちがう | beep_no |
| `surprise()` | 0.2 秒遅れ → 反射のまばたき → 目を見開く → 少し沈んで後ろへ小さく跳ぶ（高さ 5cm・12cm 後ろへ）→ 12° のけぞって固まる → 戻る。光が強く光る | 驚く・音が途切れた | beep_surprise |
| `hops(n=3, height=0.06)` | 6cm を 3 回跳ねる（宙に 0.22 秒）。宙で左右に少し回る | うれしい・できた | beep_happy・takeoff・land |
| `think(dur=2.2)` | 目が斜め上 → 胴が少し上を見て 8° かしげる → アンテナの光がゆっくり点滅 → 右足のつま先で床をたたく → ひらめく | 考える → ひらめく | beep_think → ding |
| `confused()` | 目を少し細めて上を見る → 右へ 10° かしげる（0.5 秒）→ 反対へ少し → 戻る | ？・なぜだろう | beep_question |
| `peer(dur=1.6)` | 腰から前へ 24° 曲げて 2cm 沈み、目のレンズを前へ出して絞る（ピント合わせ）、少し左右を見て戻る | のぞき込む・中を見る | zoom |
| `sigh()` | 吸う（1.2cm 伸びて少し反る 0.55 秒）→ 吐く（3cm 沈み 6° 前へ、アンテナが垂れ、目と光がゆるむ 0.9 秒）→ 戻る | ほっとする・間に合った | sigh |
| `present(yaw=45)` | 横の物を見る（目 → 胴）→ アンテナの光を 2 回点滅 → カメラへ向き直って小さくうなずく | 「これです」と紹介する | beep_present |
| `greet()` | ゆっくりまばたき → 腰から前へ 15°（0.5 秒）→ 止める（0.3 秒）→ 起きる（0.6 秒）。光があたたかく 1 回ふくらむ | あいさつ・おじぎ | beep_hello |
| `awe(dur=3.2, pitch=20)` | 目が上へ跳ぶ → 体が反る（最大 12°）→ 目の輪が少し開き、光がゆっくりふくらむ → 戻る | 大きな物を見上げて感心する | beep_wow |
| `groove(dur=4, bpm=96)` | 拍ごとに少し沈み、2 拍で左右に 1.5°。始めと終わりはなめらか | 曲に乗る | なし（曲の拍に合わせる） |
| `rest(dur=2.5)` | 目の輪をゆっくり細め（0.35 倍）、体を 4cm 沈めて前へ 6°、アンテナの光を落とす | 休む・電源が切れる | power_down |
| `wake()` | 2 回まばたき → 目が開く → 体が少し行き過ぎて伸び（2cm）戻る。光が戻る | 起きる・動き出す | boot |

### 6本目で足した動き（marumotion に足した）（2026-11-17。どれも足は地面に着いたまま、胴を脚の付け根のまわりに倒す）
| 動き | 見え方 | 長さ | 予定 | 音 |
|---|---|---|---|---|
| ころん（後ろへ転ぶ） | 見上げすぎて、胴が後ろへ 80° 倒れ、背中から床に座りこむ（0.4 秒・少し弾む）。目の輪が小さくなる。起きるまでそのまま | 約 1 秒 | `tumble_back()` | `beep_surprise` → `land` |
| 横に寝ころぶ | 右（side=1）か左へ、胴を 80° 倒して横になる（0.5 秒）。目は開いたまま。起きるまでそのまま | 約 0.9 秒 | `lie_side(side)` | `land` |
| 起き上がる | ぐっと力をためて（0.2 秒）→ 胴を起こす（0.55 秒）→ ぷるっと震える | 約 1.4 秒 | `get_up()` | `takeoff`・`land`（小） |
| すりすり（頭をこすりつける） | 前へ 16° かがみ、胴を左右に ±14° ひねりながら小さく上下（1 秒に 2.4 回）。目を細める。終わると起きる | 指定（dur）＋0.4 秒 | `rub(dur)` | `rub`（ひねるたび） |

### 荷物（データの荷物を運ぶ。1本目の決まり：荷物はトレーごと頭の小さな受け皿に載せる。頭を突き抜けない）
| 部品 | 見た目 | 音 |
|---|---|---|
| `set_carry(True/False)` | 荷物を持つ／持たない | cradle_out |
| `load_back()` | 後ろの積み込み口から積む：アンテナをしまう → 押し出し板が荷物を水平に押す。押される間は後ろへ最大 約 4.8° 踏ん張る。積んだあとは前へ 2.3°・0.55cm 沈む（荷物の重さ） | push・lock・load_done |
| `unload(bow=0.9)` | 前へおじぎ（36°）して降ろす。おじぎを速くすると荷物を投げてしまうので 0.9 秒 | unload |
| `unload_back(dock)` | 後ろの台へ（ダンプ式）：体を前へ 6° → 荷台を後ろへ傾け、荷物が滑って台へ | unload |
| `unload_pull(...)` | 台の引き込み板がトレーごと引き取る。引かれる間は前へ踏ん張る | unlock・pull・load_done |

### QR回で足した動き（`episodes/ep02_qr/pc_kit/qr/plan_util.py`）
| 部品 | 見た目 | 音 |
|---|---|---|
| `stagger(p, n=3)` | よろける：反応の遅れ → 目を見開く → 横へ小さく跳ぶ（左右交互に n 回、だんだん小さく）→ 踏んばって止まる | （場面に合わせる） |
| `tilt(p, deg=16, hold=1.8)` | 首をかしげる（長め）：目を少し細めて上を見る → 横へかしげて止める → ゆっくり戻す | 問いかけの電子音 |
- 気持ちの動き（よろける・かしげる）はアップで、はっきり大きく。カメラはまるロボを追う（SKILL.md §5）。

### 組み合わせる・カット
- `layer(t0, t1, fn)`：動きを足し合わせる。fn(t) は {チャンネル: 値} を返す。使えるチャンネル：`pitch`（前後の傾き）・`roll`（横の傾き）・`twist`（胴のひねり）・`dx`（横へ寄る）・`lift`（上下）・`gaze_yaw`・`gaze_pitch`（目の向き）・`iris`（目の輪の開き）・`zoom`（レンズを前へ）・`light`（アンテナの光）・`ant`（アンテナ）・`blink`・`tap0`・`tap1`（つま先でたたく）・`breath`・`cradle`。
- `label("説明")`：予定に説明を付ける（確認用の字幕・見本リールの字幕になる）。
- `teleport(pos, heading)`：カットで置き直す。画面に映っている所では使わない（瞬間移動に見える）。カットをまたいで歩くか、画面の外で置き直す。

## 音（`p.events` の種類 → 音の作り方。`maru_reel_assemble.py` と同じにする）
- 音の作り方は共通の `scripts/maru_sfx.py`（`make(種類, strength)`。1本目の見本リールの音そのまま。2026-11-17 共通にした。6本目で足した `rub` も入っている）。各回の効果音から、この道具を呼ぶ。
| 種類 | 音 |
|---|---|
| step | 低い「トン」（95Hz・歩幅が大きいほど大きい） |
| step_turn | 小さい「トン」（110Hz） |
| takeoff | 短い「ビュッ」（320→700Hz） |
| land | 重い「ドン」（70Hz）＋小さい金属音。着く速さが大きいほど大きい |
| beep_yes | ピ・ポ（880 → 1175Hz、上がる 2 音） |
| beep_no | ポ・ボ（700 → 480Hz、下がる 2 音） |
| beep_surprise | ピュイッ（600→1900Hz に上がって、高い音を短く） |
| beep_happy | ド・ミ・ソ・ド（1047・1319・1568・2093Hz を速く） |
| beep_think | 小さく「ポ」（520Hz） |
| ding | ひらめきの「チーン」（1568Hz の鈴） |
| beep_question | ポ・ポウ？（2 音目が上がる） |
| beep_hello | ソ・ド（784 → 1047Hz） |
| beep_present | シ・ミ（988 → 1319Hz） |
| beep_wow | 「ほぉ〜」（480→900Hz に上がって、ゆっくり下がる。`episodes/ep01_earphone/stage/ch03/ch03_assemble.py`） |
| zoom | 小さく「ウィーン」（900→1400Hz） |
| sigh | 息の音＋下がる音（420→230Hz） |
| power_down | 下がっていく「ヒューン」（900→180Hz） |
| boot | 上がる「ヒューン」→「ピ」（220→1100Hz、1319Hz） |
| cradle_out・unload | 低い「ウーン」（モーター） |
- 荷物の部品の push・lock・load_done・unlock・pull は、見本では音を付けていない。付けるときは物の動きに合わせて、`scripts/overlay2d.py` の thump・clank・motor から選ぶ。
- 同じ動きの音は同じ大きさに。頼まれていない音は足さない。大事な音は声と重ねない（SKILL.md §6）。

## 使い方の例
```python
import marumotion as mm
p = mm.Plan(pos=(0, 0), heading=180)        # カメラのほうを向いて立つ
p.idle(2.0)
p.walk_to((2.0, 0.0), label="荷物のところへ歩く")
p.peer(label="のぞき込む")
p.think(label="考える→ひらめく")
p.hops(n=2, label="わかった！")
frames = mm.simulate(p, fps=24)              # 毎コマの姿勢 → marurig で 3D に当てる
events = p.events                            # 足音・電子音の時刻
```

## 人（ピクトグラム）の動き（1本目の電車の場面。`episodes/ep01_earphone/stage/human/`）
- `motion.py`：人の動きの部品。なめらかな動き（躍度最小）、呼吸、まばたき、目の動きの速さ、電車の揺れ、つり革の振り子。
- `pose_lib.py`：スマホを持つ（丸い手がスマホを突き抜けない位置）・太ももに手を置く・耳のイヤホンに触れる・指の曲げ。
- `dance.py`：曲の拍に合わせた踊り。拍の直後にすばやく動き、ゆっくり戻る。全員が同じ振りで踊る場面（想像）と、主人公だけがノリノリの場面（現実）。音が途切れるとピタッと止まる。
- `hrig.py`：骨を動かす（腕・脚は 2 関節の逆運動学、視線）。
- 止まっていない場面の人は、小さく動かす（呼吸・視線・電車の揺れ）。物が手や頭を突き抜けない。
