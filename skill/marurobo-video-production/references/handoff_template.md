# 引き継ぎメモ（handoff.md）の形

セッションを区切るときに、`episodes/<回>/handoff.md` をこの形で書いて push する（SKILL.md §11 の 6）。
新しいセッションは、SKILL.md とこのメモだけを読んで始める。長くても 2,000 字。スキルにある決まりは写さない（読めば分かるため）。

```
# <回の名前>：引き継ぎ（<日付>、<前の工程> → <次の工程>）

## いまの状態（1〜3 行）
- 例：台本 v2.0 承認済み。声は全部できた（照合 OK）。3D は ch1〜ch3 を PC で描き終わり、ch4〜ch6 はまだ。

## ファイルの場所
- 台本：episodes/<回>/台本_v2_0_確定.md
- 声・置き場所：$MARU_WORK/stage/voice/achernar/（作業場所にしかない物は、作り直し方も書く）
- 大きな素材：どこに置いたか（ドライブ・枝 など）

## 決まったこと（この回だけの決定。スキルにないもの）
- 例：ch3 の天秤は使わない（ユーザー 11/25）

## 残っていること・次にすること（順に）
1. ...
2. ...

## 気をつける所（この回で起きたこと）
- 例：まるロボの足が床にめり込む場面が ch2 0:41 にある。描き直し待ち。

## 待っているもの
- 例：PC の描画 ch4〜ch6（drive_watch.py ch04:20 ...）・ユーザーの答え（何を聞いたか）
```
