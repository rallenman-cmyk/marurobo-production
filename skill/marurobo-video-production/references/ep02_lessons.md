## 2. なぜ多くなったか（作り方の原因）

1. **動く絵を通しで見せたのが遅かった。** v2〜v5 は静止画を並べた確認用動画で、動き・音・場面のつなぎ・画面の変化は見えなかった。PC の 3D を全部入れた v10 で、まとめて 92 件出た。→ 章が 1 つできたら、その章を動く形（3D の試し描き＋音）で自分が通しで見る。見る人が引っかかる所を先に探す。
2. **決まりが、直しのあとから増えた。** 「答えを先に見せない」「言う瞬間に出す」「矢印で指す」「点滅させない」は、v10・v13 のあとで SKILL.md に入った。→ 次の回は、作り始める前にこのページの点検表を読む。
3. **機械の点検がない所で起きた。** 1 コマだけ別の絵（v12）、声の雑音（v13）、札の点滅（v13）、場面の名前の重なり（v14）は、道具（`spike_find.py`・`voice_noise.py`・`<章>_pc.json` の used）を作ってから 0 になった。→ 新しい種類の直しが来たら、その場で直すだけでなく、次から機械で見つける方法を足す。
4. **戻された 8 件は、言われた言葉だけを直して、見た目を確かめていなかった。**
   - 「スマホの奥にはみ出てる」→ 跳び方を直したが、小さくなる中心が足元のままで、足が残った（v14）。
   - 「柄を重ねる動きを」→ 重ねる動きを足したが、外す動き（めくる）とそろえていなかった（v14）。
   - 「帯 2 に予備と書いて」→ 札を足したが、いつもの赤のままで、赤いマスの上で見えなかった（v14）。
   - 「3D にして」→ 3D にしたが、新しい音（しずく）を足して「いらない」と言われた（v14）。
   - v10 でも 4 件（帯の線のマスがずれる・点滅・一瞬違う場面・全体像を回す）。
   → 直したら、その秒を **指摘した人の目で** もう一度見る：①言われたこと ②同じ場面のほかの物（色・大きさ・向き）③前後の動きとそろっているか ④頼まれていない物を足していないか。

## 3. 点検表（作業の段ごと。全部に印を付けてから見せる）

### 台本を書いたら
- [ ] 全部の台詞を SKILL.md §4 の 8 つ（疑問を先に・指す物を省かない・理由・橋・絵が浮かぶ言葉・参加・画面と一緒に・耳で分かる長さ）で見直した
- [ ] 答えを言う文と、答えをためる文（「……」）を分けた。答えの数字・言葉が、言う前の字幕・札に出ていない
- [ ] 「さきほど」「冒頭の」と言う所に、その場面の切り抜きを入れる印を付けた

### 絵コンテ・3D を作ったら
- [ ] 同じ絵が 8 秒以上続かない（カメラの角度を変える・まるロボが動く・寄る）
- [ ] まるロボは話に合わせて動く。カットで置き直さない（歩いて移る・画面の外へ出て入る）
- [ ] 出来事（倒す・乗る・落とす）は 3D で見せる。平らな 2D の図にしない
- [ ] 光らせる物は、言う単位（箱なら箱の形）で。遠くて小さい物には 2D の矢印と札も
- [ ] 出す動きと外す動きはそろえる（めくる ↔ 逆回しで重ねる）
- [ ] 小さくして消すときは体の真ん中を中心に。物が物を突き抜けない（光・体）
- [ ] 使わない場面の物（線・弧・子の物）が残っていない
